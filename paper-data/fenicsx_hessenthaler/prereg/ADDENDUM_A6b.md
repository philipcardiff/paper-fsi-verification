# Addendum A6b (2026-11-11), registered before any s4f case is run; refines A6 item 2 (case settings)
Finding: the tutorial at 517a44921 is not the corrected protocol (it uses linearUpwind with cellLimited grad(U), inletOutlet at the outlet, couplingReuse 5, nOuterCorr 30, a non-strict coupling test, mu 58.45 kPa), while the manuscript text for the feature-edge campaign (sectionBenchmarkSuite.tex, sec:hessenthaler, repo HEAD 4dfee64) specifies: LUST convection (75 % linear / 25 % linear-upwind) with unlimited least-squares gradients, backflow-stabilised outlet (beta = 0.2) with fixed pressure, up to 20 PIMPLE outer correctors stopped at initial momentum and pressure residuals 1e-5, IQN-ILS with the modes of the two previous steps (couplingReuse 2), solid and fluid predictors, strict test both residual measures < 1e-4 from t = 0, dt = 0.002 s, S2 solid (6 240 cells), mu* = 64.2 kPa, nu = 0.45. The older paper-data report (chamfered campaign) differs (linearUpwind, couplingReuse 0, 1 outer corrector): the manuscript text is taken as the definition of the corrected protocol.
Deltas applied to the 517a44921 tutorial, and nothing else: (1) 0/fluid/U outlet: type backflowStabilisedOutletVelocity, beta 0.2, smoothing 0.01 (class defaults), value uniform (0 0 0); (2) system/fluid/fvSchemes: div(phi,U) Gauss LUST grad(U); default and grad(U) gradient schemes leastSquares (no limiter); (3) system/fluid/fvSolution PIMPLE: nOuterCorrectors 20 with outerCorrectorResidualControl {U {tolerance 1e-5; relTol 0;} p {tolerance 1e-5; relTol 0;}}, nCorrectors 3 and momentumPredictor on unchanged; (4) constant/fsiProperties: nOuterCorr 60, couplingReuse 2, requireAllResidualMeasures yes, allowUnconvergedCoupling yes (as in paper-data), outerCorrTolerance 1e-4, relaxationFactor and predictors as in the tutorial; (5) mechanicalProperties mu 64200, K 620600; (6) deltaT 0.002 unchanged. The resulting case is labelled "ours-s4f (manuscript-protocol reconstruction)"; its equivalence to Philip's unpublished feF1 runs is unverified and is not claimed.
