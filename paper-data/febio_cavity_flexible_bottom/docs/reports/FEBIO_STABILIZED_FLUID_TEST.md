# FEBIO STABILISED FLUID TEST (Stage 4): fixed-plate fluid-only cavity C1b, alpha = 3/4 (PPP)
## A. Pre-registration (written 2026-10-30 after the Stage 2 tiny-model results and BEFORE the Stage 4 C1b run; thresholds fixed now)
Case: identical to stock C1b (input byte-identical apart from one comment line; same mesh h ~ 0.1, K = 1e6, mu = 0.01, rho = 1, dt = 0.5, ramp 10, t_end 300, inlet profile/rim/pins/outlet), experimental binary, `FEBIO_PPP_ALPHA=0.75` (the single value predeclared in `FEBIO_PRESSURE_PROJECTION_DERIVATION.md` s.3.1 from the Schur-complement bound 3/(4 mu); no force or -5.25 used). 4 cores, same job script.
Rim-pressure iteration remedy (source change #2, active only for alpha > 0): the rim dilatation is re-evaluated once per time step instead of every Newton iteration (see `FEBIO_EXPERIMENTAL_BUILD.md`); without it the tiny model did not converge in 15 reformations (Newton contraction ratio 0.55) and would have needed ~43 iterations per step (about 4 CPU-h for C1b: not affordable).
### What the Stage 2 tiny straight-channel run (exact Poiseuille solution known, t = 100 s, steady, `results/T3_straight_vs_exact.json`) already predicts for Stage 4 (recorded before the run)
* y-parity amplitude: removed (0.00063 Pa rms -> ~1e-8 Pa).
* Velocity and dp/dx: error against the exact Poiseuille profile 1.0 % (stock) -> 0.26 %; dp/dx error 0.98 % -> 0.21 %.
* **Mass conservation: deteriorates.** Flux at x = 2: 0.99264 of the inlet flux (stock 1.0000002), outlet 0.99708 (stock 1.000002). Explained analytically: the per-element sum of the stabilisation rows is zero, but at the inlet nodes only the downstream element contributes, so the inlet-row sum is `sum S_i = (alpha/mu) |dp/dx| h^2 H/12 = alpha (h/H)^2 Q` = 0.75 % of Q for alpha = 0.75, h/H = 0.1 (observed 0.74 %); at the outlet the unenforced rows absorb the opposite sign. Prediction for C1b: interior flux deficit about -0.7 %, Q_out/Q_in - 1 about -3e-3, against the stock +9.06e-5.
