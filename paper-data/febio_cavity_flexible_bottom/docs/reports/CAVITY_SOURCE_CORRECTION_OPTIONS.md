# CAVITY SOURCE CORRECTION OPTIONS (B7: PROPOSALS ONLY, 2026-10-30)
Nothing here is implemented, compiled, installed or run. `upstream/febio-v4.13` is untouched (`git status` = 0 changed files). Diffs against the stock `FEFluidFSIDomain3D.cpp` are stored (not applied) in `cavity_agent/experimental_src/` (`experimental_BP_stabilisation.diff`, `experimental_PPP_stabilisation.diff`, with the modified full copies under `FEBioFluid/` and `FEBioFluid_PPP/`). Matrix evidence: `cavity_agent/pressure_mode/b7_stabilisation_check.py`, `b7_ppp_check.py` (linear algebra on the validated element operator, see `FEBIO_PRESSURE_MODE_ANALYSIS.md`). Labels: PROVEN / STRONGLY SUPPORTED / HYPOTHESIS / NOT YET TESTED. The diagnosed cause (class B, `FEBIO_PRESSURE_MODE_ANALYSIS.md` section 8) is the h^2-soft parity pressure modes of the unstabilised equal-order Q1/Q1 pair.

## Rules for any correction
No pressure averaging or filtering inside `LoadVector` or the output; no coefficient tuned to -5.25; no edit of `upstream/febio-v4.13`; a stabilisation must be a term of the weak form that is stated, tested in isolation, and reported with its own consistency error. The pair-mean (= element-average = FEBio's own surface-force definition) is a reporting quantity, not a fix.

## O0. What stock FEBio v4.13 offers through the input file (PROVEN by source inspection)
- No interior pressure stabilisation exists (only boundary `fluid backflow stabilization` / `fluid tangential stabilization`, outflow-only). Only the `fluid-FSI-3D` domain class exists, so a different velocity/pressure space (Taylor-Hood) cannot be requested: w and e_f always share the element's node set. K, dt, tolerances, the pins and the inlet options do not change the parity (existing C4 runs, attribution: fixed-value part -1e-4 Pa).
- Available only as input changes: mesh refinement (D = 0.365 / 0.173 / 0.134 Pa, F1-F2 = 0.72 / 0.34 / 0.27 N/m: the parity eigenvalue falls ~h^2 but the amplitude decays slower than h^2 and M3 is not steady); a different element shape for the fluid domain (hex20/hex27 share the same domain class, equal-order again: **NOT YET TESTED**, no inf-sup gain expected for equal order); adding the stock `fluid surface force` plot on the `Interface` surface to **report** the element-average force (parity-immune by construction, sign flipped for our facet orientation). That reports F2; it does not change the applied load and therefore not the plate displacement.
- **Conclusion: a stock-FEBio correction of the applied load is not available without a source change. NOT a claim that FEBio is incapable of the benchmark.**

## O1. Polynomial pressure projection (PPP, Dohrmann-Bochev): recommended first candidate (HYPOTHESIS for the coupled benefit)
- **Basis.** Add to the continuity row `-(alpha/mu) int (p - Pi p)(q - Pi q) dV` with `Pi` the element-mean projection (p = -K e_f). In e_f variables: residual `fJ_i += (alpha K/mu) int N_i (e_f - mean_el e_f) dV`, tangent `kJJ_ij += (alpha K/mu)[int N_i N_j - (int N_i)(int N_j)/V_e]` (one extra rank-1 term per element, no new DOFs). Diff: 37 added lines.
- **Matrix evidence (PROVEN as linear algebra on the validated operator):** straight channel h = 0.2/0.1: parity eigenvalues of the Schur operator rise from 4.0e-3/1.0e-3 (y), 1.2e-2/3.4e-3 (checker), 2.4e-2/6.6e-3 (x) to **25 (alpha = 0.25)**, independent of h; the smooth mode moves 0.1014 -> 0.1183 (h = 0.2, +17 %) and 0.1045 -> 0.1089 (h = 0.1, +4.2 %): the consistency shift scales ~h^2. Cavity M1 **without pins**: the two corner eigenvalues 3.5e-10 and 4.1e-10 become part of a spectrum with lowest eigenvalue 0.087: the corner DOFs are determined by the term, so the pins would no longer be needed (HYPOTHESIS for the nonlinear solver; the coupled behaviour was not run).
- **Scaling with h.** Stability: lam_parity ~ alpha/mu (h-independent). Consistency error: `(p - Pi p) ~ h grad p`, so the added term is `(alpha/mu) h^2 |grad p|^2`-sized: O(h^2) relative to the viscous scale, i.e. same order as the Q1 interpolation error; it vanishes with refinement. Choice of alpha: a stability-analysis constant (O(1)), set before any run (proposed values 0.25, 1, 4 as a sensitivity bracket, none selected by a force target).
- **Consistency with the continuum equations.** For piecewise-constant (element-mean) pressure the term vanishes; for smooth p it is O(h^2) (above). Not residual-based (not a Galerkin-consistent method in the strict sense), but the perturbation is bounded and symmetric positive semi-definite.
- **Residual/tangent.** Residual change `+gamma K N_i (e_f - e_bar) detJ`; tangent adds a symmetric element matrix with zero row and column sums; no change to the momentum rows or to the u-coupling; the Jacobian remains valid for the Newton iteration (finite-difference tangent check listed below).
- **Conservation.** `sum_i int N_i (e_f - e_bar) dV = int (e_f - e_bar) dV = 0` exactly per element: **the stabilisation adds no net mass source and no boundary flux** (column sums of the matrix are 1e-18 in `b7_ppp_check.py`). Global flux balance is unchanged by construction (PROVEN algebra).
- **Unit test design (source level and element level).** (a) Element FD test: perturb each of the 56 element DOFs, compare `ke` with the numerical derivative of `fe` (relative 1e-6); (b) null space: `ke` rows sum to zero in the e_f block for a unit e_f vector; (c) patch test: uniform e_f gives zero added residual, linear e_f gives an O(h) residual; (d) parity test: the 2x2-element checkerboard e_f field returns the added energy `(alpha K^2/mu) sum (e_i - e_bar)^2 V/4`; (e) assembled-operator test: reproduce the spectra of `b7_ppp_check.json` from a small FEBio input (4 x 4 x 1 hex8 patch, `alpha` set by the env flag) via the tangent matrix dump; (f) alpha = 0 reproduces the stock binary's output bit-for-bit on a tiny model.

## O2. Brezzi-Pitkaranta pressure Laplacian (simplest; not conservative at boundaries)
- **Basis.** `fJ_i += tau K int gradN_i . grad(e_f) dV` (= `-tau int gradN_i . grad p`), `tau = alpha h_e^2/mu`; tangent `kJJ += tau K gradN_i . gradN_j detJ` (SPD). Diff: 24 added lines.
- **Matrix evidence (PROVEN algebra):** `alpha = 1/48` raises the parity eigenvalues to about 25 at h = 0.2 and 0.1; the smooth mode shifts +5 % (h = 0.1) and +20 % (h = 0.2), again ~h^2 (`b7_stabilisation_check.json`).
- **Consistency/conservation.** Consistency error `tau nabla^2 p = O(alpha h^2/mu) |nabla^2 p|` (vanishes with h; it is zero for linear p only in the interior). **Not conservative**: the weak form has the boundary flux `tau dp/dn` through walls and outlet; the relative mass imbalance is estimated as `alpha h^2 |dp/dn| / (mu U)` (about 7.5e-3 alpha at h = 0.025 with dp/dx = 0.12 Pa/m, i.e. 1.6e-4 for alpha = 1/48) and must be measured (`Q_out/Q_in - 1` already logged). Second choice after O1 because of this boundary flux.
- Unit tests as O1(a), (c), (d), plus a flux-balance test on a Poiseuille patch.

## O3. PSPG-type (residual-based, fully consistent), longer term
- **Basis.** Add `sum_e tau_e int gradN_i . (rho a + grad p - div sv) dV` to the continuity row with the momentum residual evaluated at the Gauss points; `tau_e = (1/tau_t^2 + (2|w|/h)^2 + (4 mu/(rho h^2))^2)^(-1/2)` (Tezduyar-type, no free constant). Consistent for the exact solution (zero residual), no O(h^2) modelling error, stabilises the convective cell-Re > 2 regime too (the attribution assigns 58 % of D at M1 to the convective force).
- **Cost.** The tangent needs the derivative of the momentum residual with respect to w, e_f and the ALE terms (u, m_L, m_aft): a larger diff than O1/O2 (est. 100+ lines), risk of breaking the fluid-FSI tangent consistency. Not diffed here. Conservation: residual-based terms do not conserve exactly (boundary flux like O2).

## O4. Boundary/pin treatment (setup, not a cure for the parity)
The four corner pins remain a necessary determination of an otherwise undetermined DOF (`FEBIO_PRESSURE_MODE_ANALYSIS.md` section 3); they contribute 1e-4 Pa to D. With O1 the pins become unnecessary (matrix evidence only). Without O1, an alternative to the constant pin is an algebraic condition tying the corner dilatation to its neighbour (not available through the stock input; NOT YET TESTED).

## O5. Mesh changes
Refinement shrinks the parity eigenvalues ~h^2 and the observed D slowly (0.365 -> 0.173 -> 0.134 Pa); an unstructured or rotated mesh would change which patterns are soft but not remove them (P1/P1 is unstable too; NOT YET TESTED). A single further refinement (M4, about 110 CPU-h) is not recommended as a diagnosis.

## O6. Ruled out as corrections (documented to prevent misuse)
- Averaging the wall-row pressure with the next row (or the element pressure) inside `FEFluidFSITraction::LoadVector`, or smoothing the output: this changes the load to F2/F4 by a filter without a stability argument, would hide the soft modes in the velocity solve, and agrees with the reference at M3 only (+6.1 % at M1, +0.9 % at M2).
- Tuning alpha so that F1 = -5.25.

## Which option is justified?
A **mathematical** source correction is justified as an *experiment*: the diagnosed soft-mode mechanism is PROVEN for the linear operator and the PPP term cures it in the operator (PROVEN algebra) while being exactly conservative. Whether it removes the cavity force gap is NOT YET TESTED and could be negative (the gap could have a second cause: s4f's own interface treatment, or the 5 % deficit may include a real fluid effect). The test is specified in `CAVITY_MINIMUM_VALIDATION_PLAN.md`.
