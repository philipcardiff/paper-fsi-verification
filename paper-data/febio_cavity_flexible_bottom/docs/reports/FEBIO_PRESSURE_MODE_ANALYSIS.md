# FEBIO PRESSURE MODE ANALYSIS (B4) and CLASSIFICATION (B6), 2026-10-30
Question: is the row-parity (alternating) nodal pressure of the cavity runs a (near-)null mode of FEBio v4.13's equal-order hex8 fluid element, why is it absent in the straight channel, and what does it do to the interface load? Mathematics from the source blocks (`FEBIO_V413_PRESSURE_SOURCE_AUDIT.md`), small sparse/dense matrices on the login node, existing run data only. No FEBio run, no solids4foam, no job. Scripts and data: `cavity_agent/pressure_mode/` (`b4_operator.py`, `b4_residual_check.py`, `b4_pressure_attribution.py`, `b4_modal_scaling.py`, `b4_transient_stokes.py`, `b4_straight_channel.py`, `b4_straight_profile.py`, `b7_stabilisation_check.py`, `results/*.json`). ## 1. The discrete operator and its validation
Plane-strain, z-uniform fields (hex8 one layer, wz = 0, 8-pt Gauss reduces to 2-D Q1, 2x2 Gauss, thickness 1); linearisation about rest (w0 = 0) on a fixed mesh from `ElementStiffness`/`ElementMassMatrix`: `Kww = int gradN_i.cv.gradN_j (+ rho c N_i N_j)`, `kwJ = -K int N_i gradN_j`, `kJw = int gradN_i N_j`, `kJJ = c int N_i N_j`; in p = -K e_f: `[A G; G^T -(c/K) M]`, mu = 0.01, rho = 1, K = 1e6, dt = 2.5 (rhoi = 0, order 2: c = 0.5333), c/K = 5.3e-7.
- **PROVEN:** `max|kJw - G^T| = 1.7e-17` (continuity coupling is exactly the transpose of the pressure-gradient coupling).
- **PROVEN (validation of my assembly on FEBio's own field):** on the converged fixed-plate fluid-only solution C1b (nodal w, e_f from `Mon_all.txt`, t = 300 s; strong-form pressure gradient + viscous + convective `rho N_i (grad w) w`, continuity with the inlet flux load of `FEFluidNormalVelocity::LoadVector`) the free-row momentum residual is 7.1e-8 against a pressure-gradient norm 7.6e-2 (**relative 9.4e-7**, max 1.6e-8) and the free continuity residual is 7.6e-8 against |G^T w| = 0.344 (**2.2e-7**) (`b4_residual_check.json`). So the reassembled equations are FEBio's discrete equations, including the pressure with its alternation. This also fixes the inlet-load sign: `G^T w + b = 0`, b = int N_i phi.

## 2. Is the alternating pressure a null mode? No: a soft, h^2-degenerate mode (Schur analysis)
Eliminate w: `S = G^T A^-1 G` (pressure Schur complement); generalised eigenproblem `S q = lam M q` on the free pressure DOFs (walls/interface/inlet w fixed, outlet and rim p fixed), straight channel 14 x 1, h = 0.2 and 0.1 (`b4_modal_scaling.json`):
| mode class (edge sign-change fraction x/y) | lam, h = 0.2 | lam, h = 0.1 | ratio |
|---|---|---|---|
| y-parity (x-smooth envelope) | 4.04e-3 | 1.02e-3 | **3.97** |
| checkerboard (x and y) | 1.20e-2 | 3.43e-3 | 3.51 |
| x-parity (y-uniform) | 2.41e-2 | 6.63e-3 | 3.63 |
| smooth (lowest) | 0.1014 | 0.1045 | 0.97 |
- **PROVEN (two mesh levels, one geometry):** the parity families have lam proportional to h^2 (ratio about 4) while the smooth mode is h-independent: this is the inf-sup deficiency of the equal-order Q1/Q1 pair without stabilisation (beta_h ~ h). At h = 0.1 the softest parity mode is 100 times softer than the softest smooth mode. The y-parity (the pattern observed in the cavity) is the softest of the three.
- **PROVEN (algebra):** an interior x-uniform y-alternation q = (-1)^j gives `G q = 0` at every free momentum row of a uniform grid (central difference of an alternating sequence is zero), so the pattern is an exact null of the interior gradient; the outlet condition (q = 0 at the outlet column) and the corner/wall rows make it only a near-null: `lam` is 1e-3, not 0.
- **Not a neutral mode:** lam (>= 1e-3) is about 2000 times larger than the compressibility term c/K = 5.3e-7. In a backward-Euler emulation of the cavity M1 (Stokes + inertia, same BCs, K 1e6 / 1e7, dt 2.5 / 1.25) a 0.1 Pa y-parity perturbation of rows 0-7 over x in [2.5,5.5] is removed within **one step** and the field returns to the same steady value (D = 0.0326 Pa in every variant) (`b4_transient_stokes.json`). **A "null mode with memory" is REJECTED for the linear Stokes operator** (PROVEN within the emulation; the nonlinear coupled solver was not run). The alternation is a **forced steady response** amplified by the soft modes, not a stored history.
- Cavity M1 with the model's BCs (`cavity_f1_pin`): lowest eigenvalues 2.54e-3 (checker-type, centroid (4.25, 1.18)), 4.9e-3 (y/x-parity), 1.21e-2 (smooth-type next at ~1.2e-2 in the dt = 2.5 list); the soft modes are broad (participation 750-1260 of 1832 nodes), not localised at the floor. This only says the operator has soft parity modes anywhere in the channel/cavity.

## 3. Corner nodes and the four pins (B5 link; PROVEN)
Without pins the cavity M1 operator has two eigenvalues 3.5e-10 and 4.1e-10, each carried by one floor-end corner pressure DOF ((6,0) and (2,0); the two z layers are collapsed): these corner DOFs couple to the momentum rows only through the one free diagonal neighbour (|G column| = 0.0122, 2 entries) and are 7e6 times softer than the next mode and 700 times softer than c/K. This reproduces the C1 observation (corner pressure drifting linearly in time with the geometric neighbour series 641, -172, 46, ... ratio -0.268 = -(2 - sqrt 3), `CAVITY_FLUID_ONLY_RESULTS.md`): a pressure DOF that the discrete equations do not determine integrates any constant source in time. **The pin is a necessary determination of an otherwise undetermined DOF, not a physical condition.** With the 2 (x2 layers = 4) corner pressures pinned, G has full column rank and the lowest eigenvalue is 2.5e-3 (`b4_operator_spectra.json`). Removing the pins blindly would reproduce C1 (floor drift 2-45 Pa per 100 s, odd-even amplitude 149 Pa, Fy -70 N/m).

## 4. What creates the amplitude: exact attribution on FEBio's own field (C1b)
Since G has full column rank, the momentum equation `G_f p = -(A w + conv(w))_f - G_fixed p_fixed` makes p a linear function of the force terms. Solving it by least squares for each term separately with the same operator (`b4_pressure_attribution.json`; reconstruction error of p 2.4e-7):
| part | D = mean(p_row1 - p_row0), x in [2.4,5.6] | mean wall-row p |
|---|---|---|
| viscous force `-A w` | **+0.177 Pa** | 0.992 |
| convective force `-conv(w)` | **+0.240 Pa** | 0.170 |
| fixed values (outlet 0, rim, 4 pins 1.15 Pa) | **-0.0001 Pa** | 0.0001 |
| sum = FEBio field | **0.417 Pa** (field 0.417) | |
- **PROVEN (linear algebra on the validated operator):** the corner pins, the outlet and the rim pressure contribute 1e-4 Pa to the row parity (0.03 % of D). The parity is produced by the flow's own force terms: 42 % by the viscous force of FEBio's velocity field, 58 % by the convective force. A boundary-value or setup cause is excluded for C1b; the same operator with the same BCs in a Stokes emulation (no convection) gives only D = 0.033 Pa, i.e. the real amplitude needs the real (Re = 100, separated) velocity field.
- **HYPOTHESIS (mechanism chain, consistent with sections 2 and 4, not isolated):** the discrete forces carry small components along the left singular vectors of the soft parity modes of G (rapid cell-scale structure of the velocity/convective field, the equal-order velocity error), and p = G^+ f divides them by sigma ~ h. The sections 2 and 4 data are consistent with this; I did not measure the left-singular components.
- The alternation is present across the whole domain, not at the floor only (C1b rms of p minus the mean of the 4 edge neighbours: inlet x < 1 0.395 Pa, channel above the cavity 0.216, cavity 0.217, downstream 0.240 Pa): a **global property of the discrete pressure**, consistent with the audit's note of 1.19/1.61 Pa alternation at x ~ 1. The G-image of the near-floor parity patch is not zero in the actual field (|G p_parity| = 0.30 |G p| on rows 1-4, x in [2.8,5.2]: its x-modulation couples to the momentum equation), so the pattern is not momentum-invisible.

## 5. Why the straight channel does not show it (STRONGLY SUPPORTED; partly measured)
- FEBio B0 (straight Poiseuille, 140 x 10 cells, h = 0.1, K = 1e6, dt 0.5): an x-sawtooth of 0.01239 Pa (frozen from t = 20 s) and a y-alternation of 0.00126 Pa, against D = 0.134-0.417 Pa in the cavity.
- The same linear operator + BCs + backward Euler reproduces the **x-sawtooth at 0.0089 Pa** (72 % of FEBio's 0.0124, same sign pattern, uniform along x for x in 1-10, identical for dt 0.5/0.25 and K 1e6/1e7, dp/dx = -0.12121 exactly), reaching its frozen value by t = 35 s (`b4_straight_channel.json`, `b4_straight_profile.json`). It is a **steady forced response of the discrete BVP (an end-condition offset between the odd and even sublattices of the x-gradient stencil), independent of K and dt**: "frozen" in FEBio is steady state, not neutrality. At h = 0.05 the emulated amplitude falls to about 0.003 Pa (noisy two-level estimate). **My emulated y-alternation at x = 7 (-0.027 Pa) does not match FEBio's 0.00126 Pa; I did not resolve that discrepancy.**
- Fully developed Poiseuille flow has no convective force and a viscous force that is a pure uniform gradient, so almost nothing excites the soft parity modes (only the end offsets). In the cavity the flow separates and recirculates: both the viscous and convective forces of the solution have cell-scale content (section 4: 0.177 + 0.240 Pa). The soft-mode eigen-structure is the same in both geometries (section 2 is for the straight channel); the difference is the forcing. Non-uniform block geometry, corners, pins and the inlet rim treatment are excluded as the source of D by the attribution (1e-4 Pa).

## 6. Which patterns, and the traction (D)
- Soft families, in increasing lam (h = 0.1): y-parity 1.0e-3, checker 3.4e-3, x-parity 6.6e-3 (straight channel). The cavity data show y-parity (rows alternating, x-smooth) at D = 0.13-0.42 Pa, x-parity at rms 0.016-0.04 Pa along the wall row.
- **Traction generated through the FSI load vector (PROVEN algebra + data):** `LoadVector` uses only the 4 facet-node e_f, so a wall-row offset `-a` relative to the smooth value changes the load by `-a * L` per unit depth in Fy: -(-0.067)*4.03 = +0.267 N/m at M3 (observed F1 - F2 = 0.266), +0.720 (M1), +0.341 (M2). The parity mode has zero first-order effect on F2/F3/F4 (the element mean averages rows 0 and 1).
- Effect on the solution fields: the alternation is not momentum-invisible but does not affect the flux (mass imbalance 2e-5), velocity, or the pair-mean pressure gradient (B0: 2.4e-7 Pa linearity).

## 8. Classification (B6)
- **CLASS B, discrete numerical deficiency (equal-order unstabilised Q1/Q1): STRONGLY SUPPORTED** for the existence and size of the parity (evidence above). It is the best-supported class. It does not yet establish that removing the parity restores the benchmark force.
- **CLASS A, setup error: not supported.** Pins are necessary (section 3) and contribute 1e-4 Pa to D; inlet flux/profile, outlet p = 0, no-slip, plane strain, and the interface orientation were checked in the contract/audits; the rim pressure is lagged but contributes nothing visible. The generator was not changed. One open setup question that cannot be closed here: the wall-normal resolution (`CAVITY_PRESSURE_FORCE_AUDIT.md` section 7).
- **CLASS C, source defect: not supported.** The reassembled equations match FEBio's converged state to 1e-6; the behaviour follows from the documented element choice. Observation only: the FSI load (F1) takes the wall-row nodal pressure while the plot definition uses an element average, so the two pathways disagree by 5-13 % in the presence of the mode; that is a property of the unstabilised field, not an implementation error. (A harmless copy/paste `Hs = Gr` in `FESurface::LoadVector` was noted; unused by this load.)
- **CLASS D, inadequate evidence: applies to the force deficit.** That the 5 % gap to solids4foam is entirely the parity bias is **not established**: F2 = -5.2494 matches s4f -5.2504 at M3 but misses by +6.1 % at M1 and +0.9 % at M2, no s4f pressure/traction field exists to compare, F1's viscous part is unreconstructable, and all coupled runs ended abnormally with M3 not steady to 1e-4.
- Bottom line: the alternating mode is real in FEBio's output and contaminates the applied load (F1 is 0.27-0.72 N/m, 5-13 %, below the parity-free values); the mechanism is the soft parity modes of the unstabilised pair, excited by the flow's own viscous/convective force terms (HYPOTHESIS for the exact amplification chain); a source defect is not demonstrated.
