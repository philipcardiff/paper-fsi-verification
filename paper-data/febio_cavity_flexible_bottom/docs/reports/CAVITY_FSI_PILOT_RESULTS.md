# CAVITY C2: first coupled FEBio fluid-FSI pilot (CAVITY agent)
## PRE-REGISTRATION (written 2026-10-30 before the run)
Run `runs/cavityNext/C2_fsi_pilot_f1`, generator `tools/make_cavity_fsi_feb.py`, input sha256 b449a69c...dc705, pristine v4.13, 4 cores, Slurm main.
Model: the validated 15-block cavity fluid mesh (1688 hex8, dx = 0.1) + a StVK plate (E = 500, nu = 0.4, rho = 1000) of 40 x 4 hex8 cells whose top-row nodes ARE the fluid interface nodes (conformal, shared nodes, both z layers); plane strain (u_z = w_z = 0 everywhere); plate ends clamped over the full end faces; fluid rho = 1, mu = 0.01 (Re = 100), weakly compressible K = 1e6; fluid-FSI mixture with a massless neo-Hookean mesh regulariser E_mesh = 1e-3 Pa (nu = 0, the ring value); no-slip: relative fluid velocity w = 0 on walls and interface nodes; `fluid-FSI traction` on the 40 interface facets; validated parabolic `fluid normal velocity` inlet; outlet p = 0; fluid mesh displacement fixed on walls/inlet/outlet; corner dilatation pinned at 1.15 Pa on the 4 floor-end corner nodes (documented stabilisation, see CAVITY_FLUID_ONLY_RESULTS.md C1/C1b); rhoi = 0 (generalised-alpha with maximum high-frequency dissipation); dt = 2.5 s, inlet ramp 25 s, t_end = 1250 s (500 steps). Start-up: dynamics from rest; the plate's lowest dry period is about 50 s, so the route to steady state is via numerical dissipation (generalised-alpha) and fluid damping; **steady state independence of dt/start-up is a separate C4 test, not assumed**.
Criteria (fixed now):
- P1 normal termination, 0 errors, no negative Jacobian, no cut-backs; relative Newton criteria met on the non-degenerate steps.
- P2 steady: relative spread of u_y(A) and u_x(A) over t in [1125,1250] < 1e-4 (verification README criterion); a run that has not settled is NOT compared with the references.
- P3 inlet flux 1.0000 +/- 1e-4; outlet and x = 13 flux within 1e-3 of the inlet at the end.
- P4 interface/traction transfer: the plate top displacement equals the fluid interface displacement (shared nodes: by construction); the integrated vertical fluid force on the deformed interface (pressure; viscous part estimated and reported) vs the vertical force implied by plate equilibrium (clamp shear from end-face element stresses, approximate, 5 % tolerance because the end-face estimate is crude); both reported.
- P5 plate response sanity: u_y(A) < 0, u_x(A) small; fluid mesh Jacobians positive (solver reports).
References for comparison only (never targets): at dx = 0.1 solids4foam u_y(A) -0.2046 (partitioned) / -0.2036 (QM), F_y -5.12 N/m; extrapolated -0.2407 m, -5.26 N/m. Expected FEBio-specific offsets already known: hex8 plate at 40 x 4 is 4.5 % too stiff in the plate-only check (S1: -0.23026 vs -0.2410), the odd-even pressure mode limits the force to about +/-3 %, the corner pin adds 0.2-0.4 %. A discrepancy larger than these must be investigated, not tuned away.

Cost: 914 s FEBio wall (15:14), 4 cores = 1.02 core-h allocated (3657 CPU-s), 277 MB, 7.14 Newton iterations/step (max 25), 0 cut-backs, no negative Jacobian reported.
Termination: step 390 "Max nr of reformations reached": the relative dilatation criterion (required 1.66e-34 = 1e-12 x the step's own increment 1.3e-22) sat on the arithmetic floor (1e-33); every other norm was at 1e-25..1e-27 and decreasing. This does not satisfy the brief's requirement that force accuracy accompany displacement accuracy; it is a basis for the mesh study, not a verification.

## P4 traction-transfer check S2 (pre-registered 2026-10-30; 10th and last budgeted cavity simulation)
`runs/cavityNext/S2_plate_hex8_fsiM2pressure`: the same hex8 80 x 8 StVK plate as in C3_fsi_M2 (plane strain, clamped ends) loaded **only** by the final-time interface pressure of C3_fsi_M2 (face-constant follower pressure = mean of the two nodal pressures per facet; the nodal odd-even mode largely cancels in the face mean). Criterion: u_y(A) within 2 % of the FSI value -0.226233 m. This tests that the pressure the fluid reports on the interface reproduces the plate deflection that FEBio's `fluid-FSI traction` produced (viscous shear omitted: |Fx_visc| ~ 0.02 N/m). A pass supports the pressure-transfer part of the coupling; it does not test the viscous traction or the odd-even mode.

### S2 result (Slurm 14025, 2 cores, 5 s): **PASS**
Plate-only u_y(A) = **-0.226176 m** under the C3_fsi_M2 interface pressure, against the coupled M2 value -0.226233 m: **difference 5.7e-5 m = 0.025 %** (criterion 2 %). u_x(A): 3.92e-4 (plate-only, pressure only) vs 3.35e-4 m (coupled). Supported: the pressure that FEBio's fluid field reports on the interface, applied as a follower load to the same plate, reproduces the coupled deflection, i.e. the `fluid-FSI traction` transfer of the pressure part is consistent with the structure to 0.03 % (conformal shared-node interface). Not tested: the viscous traction (small, 0.4 % of F_y at most), a force-balance check against plate reactions, and whether the nodal pressure field itself is accurate. **Consequence for the force deficit:** the 5.6-7.9 % lower F_y than solids4foam at the same dx is a property of FEBio's fluid pressure on the floor (level 1.05-1.39 Pa vs about 1.28-1.31 Pa for solids4foam), not of the coupling or of the load transfer.
