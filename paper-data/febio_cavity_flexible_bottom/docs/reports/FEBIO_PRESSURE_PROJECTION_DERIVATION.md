## 1. Weak form
Stock mass (continuity) equation, per test function q (nodal N_i), in terms of the nodal dilatation:
`R_i^J = int N_i [ (Jf'/Jf - Js'/Js) dtrans + grad e_f . w / Jf ] dV + int gradN_i . w dV (+ inlet flux load)` (FSI); `int N_i e_f'/Jf + int gradN_i . v` (fluid-only).
Added local polynomial pressure projection term (Dohrmann-Bochev 2004, Bochev-Dohrmann-Gunzburger 2006), with Pi the L2 projection onto element-constant functions:
`S_i = - (alpha/mu) int_Omega_e N_i (p - Pi p) dV ,  p = P(e_f),  (Pi p)_e = (1/V_e) int_Omega_e p dV, V_e = int_Omega_e dV.`
Equivalently the bilinear form `-(alpha/mu)(p - Pi p, q - Pi q)` (since (Pi p, q - Pi q) = 0). Sign: in the p variable the stock pressure block is `-(c/K) M` (negative definite); the term adds `-(alpha/mu)(M - M_Pi)` of the same sign: an extra, zero-mean-per-element compressibility acting only on the non-constant part of p. No other equation changes (momentum rows and solid rows untouched).

## 2. Representation with FEBio's nodal dilatation DOFs
Gauss quadrature of the element (8-point hex8): W_q = detJ_q w_q (FSI: `detJt(el,q,alphaf)*gw`, current configuration at the alphaf state; fluid-only: `detJ0*gw`, reference = current because the fluid mesh is fixed). p_q = P(e_q), e_q = sum_a N_a(q) e_a. Then
`V = sum_q W_q ,  pbar = (1/V) sum_q W_q p_q ,  S_i = - (alpha/mu) sum_q W_q N_i(q) (p_q - pbar)`.
Linear fluid (`FELinearElasticFluid`, all cases here): p = -K e, so `S_i = + (alpha K/mu) sum_q W_q N_i (e_q - ebar)`, which is the earlier diff's form. I implement the general P(e) form, using dp_q = `Tangent_Pressure_Strain(mp_q)` per Gauss point.

## 3. Units and scaling
[p] = Pa, [mu] = Pa s, so [alpha/mu * p * N dV] = m^3/s (per depth) = the unit of every term of the continuity row (`int N e'/J dV`). alpha is DIMENSIONLESS. The coefficient has no K and no h in it: K only converts e to p; h enters through (p - Pi p) = O(h |grad p|). In e_f variables the diagonal coefficient is gamma_K = alpha K/mu [1/s], to be compared with c = alpham/(alphaf gamma dt) [1/s] of the compressibility mass term (c/K in p units).
### 3.1 Choice of the one nonzero value alpha = 3/4 (declared before any alpha > 0 run; NOT from any force)
The stabilisation must be of the size of the Schur-complement upper bound so that it lifts the h^2-soft pressure modes (S eigenvalues 1e-3..3e-3 against M, from `b4_modal_scaling`) to the O(1/mu) scale without exceeding it. Upper bound of the continuous pressure Schur complement for FEBio's Newtonian law (kappa = 0, stress `s = (kappa - 2mu/3) tr(D) I + 2 mu D`, `FENewtonianFluid.cpp:68-80`): for u in H^1_0, `int eps:eps = (1/2) int |grad u|^2 + (1/2) int (div u)^2 >= int (div u)^2` (since int |grad u|^2 = int |curl u|^2 + int (div u)^2). The viscous energy is `2 mu int (eps:eps - (1/3)(div u)^2) >= 2 mu (1 - 1/3) int (div u)^2 = (4 mu/3) ||div u||^2`, therefore `sup_u (p, div u)^2 / (a(u,u) ||p||^2) <= 3/(4 mu)`, i.e. S <= (3/(4 mu)) M. Matching the stabilisation to this bound gives alpha/mu = 3/(4mu): **alpha = 3/4** (the "1/(2 mu)-type" scaling for the pure 2 mu eps form would be 1/2; the actual kappa = 0 constitutive law gives 3/4). It is a stability-analysis constant. It was fixed here, using only the operator algebra and the constitutive law, not any run output and not the solids4foam force. Caveat: the bound is for Dirichlet velocity; the outflow boundary is traction-free, so it is an order-of-magnitude scale, which is all the method needs (stability holds for any alpha > 0). Expected side effect from the operator data (`b7_ppp_check.json`): at alpha = 0.25 the lowest smooth Schur eigenvalue shifts +4.2 % (h = 0.1), so about +12 % at alpha = 3/4 in that Stokes linearisation; whether that matters for the solution is exactly what Stage 4 tests.

## 4. Residual contribution
Fluid-only (`ElementInternalForce`, row index 4i+3): `fJ_i += -(alpha/mu) sum_q W_q N_i(q)(p_q - pbar)`; FSI (7i+6): same with the current-configuration W_q. Applied before the `fe -= fJ` sign so it enters exactly like the other continuity terms. The term does not use `dtrans` (it is algebraic, not a rate: it survives in steady analyses, which is intended).

## 5. Consistent Jacobian
All derivatives of `fJ_i^stab` (ke is +d fJ / d dof, the stock sign convention):
* wrt e_j: `d p_q/d e_j = dp_q N_j(q) alphaf`. `d pbar/d e_j = (1/V) sum_q W_q dp_q N_j(q) alphaf`.
  `ke[i][j] += -(alpha/mu) [ sum_q W_q N_i(q) dp_q N_j(q) - (sum_q W_q N_i(q)) (1/V) sum_q' W_q' dp_q' N_j(q') ] alphaf`.
  For linear P: `alpha K/mu [ M_ij - I_i I_j / V ]` (I_i = sum_q W_q N_i): symmetric, PSD, constants in the null space (rows and columns sum to zero).
  The stock stiffness routines already multiply their `detJ` by `tp.alphaf`; the shared routine takes the factor explicitly.
* wrt w, v: none.
* wrt u (FSI domain only; fluid-only mesh fixed): W_q depends on x via detJ_q: `dW_q/dx_j = W_q gradN_j(q)` (spatial gradient at the alphaf configuration). With `Dq = p_q - pbar`: `d fJ_i/d x_j = -(alpha/mu)[ sum_q W_q gradN_j(q) N_i(q) Dq - I_i g_j ]`, `g_j = (1/V) sum_q W_q gradN_j(q) Dq`. The p_q themselves do not depend on x (e_f is a DOF). It is added to kJu (times alphaf).
This is tested against finite differences in Stage 2.

## 6. Finite deformation, reference vs current, ALE
In the fluid-only module the mesh is fixed (reference = current). In the FSI domain all stock continuity integrals are over the (alphaf-)current element volume (`invjact/detJt`), and e_f is the dilatation measured from the reference; p = P(e_f) is a spatial pressure. The projection is a purely geometric volume average of p over the current element; there is no time derivative of the term, hence no ALE/mesh-velocity contribution and no dependence on beta, gamma except through the alphaf evaluation point. Under large motion Pi p remains the current-volume mean; the Jacobian wrt u above accounts for the changing W_q. For the small interface deflection of the cavity (|u| ~ 0.1 m on a plate) the geometric part is a small correction; it is included, not assumed negligible.

## 7. Element geometry
The same quadrature (8-point Gauss, weights W_q including detJ_q) defines V, I_i, pbar and the residual. Hence Pi is exactly the discrete L2 projection onto constants in the quadrature inner product for ANY hex8 shape (affine or not): constant p gives p - pbar = 0 exactly (to rounding), the matrix `M - I I^T/V` is exactly rank-deficient by one (constants) and PSD. The term is a scalar form, invariant under rigid rotation of the element and under node-numbering rotations. No new geometric quantity (h, aspect) enters, so there is no element-size parameter to choose.

## 8. Prescribed pressure / dilatation conditions
Constraints remove the rows and columns of the constrained e_f DOFs from the solved system; the nodal values still enter `p_q` and pbar through the element, so the projection of an element touching the outlet (p = 0), a corner pin (1.15 Pa), or a rim node sees the prescribed value as data. The stabilisation rows OF the constrained nodes are not solved (they become reaction-like, s.9). It adds no new essential condition.
**Found in Stage 2 (not anticipated in the first version of this derivation):** the inlet `prescribe_rim_pressure` constraint is a SOLUTION-DEPENDENT prescribed e_f (value = mean of the other inlet e_f, re-evaluated at every `Update`, i.e. every Newton iteration) whose dependence on the inlet unknowns is absent from the assembled Jacobian (a lagged constraint). In the stock scheme the rim e_f only enters neighbouring momentum rows, so the omission is harmless (quadratic convergence on the tiny model, 5-7 iterations/step). The PPP term couples the rim value into the continuity rows of the neighbouring nodes with the large coefficient alpha K/mu, so the omitted coupling is O(1): Newton converged only linearly (contraction 0.55, 43 iterations per step with max_refs 60, failure with max_refs 15). Diagnosis (tiny straight-channel model, `runs/cavityExp/T1*`): without the rim constraint the same alpha = 0.75 term converges quadratically (4 iterations per step), so the element tangent is consistent (also checked by finite differences, s.5). Remedy (source change #2, active only for alpha > 0; alpha = 0 keeps the stock per-iteration update exactly): the rim value is re-evaluated once per time step (when the model time changes), i.e. it is a constant inside the Newton iterations of a step, as the corner pins are. The converged discrete state is the same fixed point (rim = mean of the inlet e_f); only the transient path to it differs. Result: 4 iterations per step again. The pins stay in the input (the model is not changed); whether the term makes the pins unnecessary was a matrix-level hypothesis (no-pin spectrum 0.087) and is NOT TESTED here and not exercised.

## 9. Mass conservation (derived from the implemented equations; corrected after Stage 2/4)
Per element `sum_i S_i = -(alpha/mu) sum_q W_q (sum_i N_i)(p_q - pbar) = -(alpha/mu) sum_q W_q (p_q - pbar) = 0` EXACTLY (algebra, any geometry, any P; verified to 5e-16 on the C1b field: `sum S = 5.4e-16`). Consequences:
(a) the term moves "mass" only between nodes of the same element; the sum over ALL continuity rows is unchanged.
(b) **BUT the flux balance that matters is not the all-row sum.** The rows of constrained-e_f nodes (outlet, 4 pins, rim) are not enforced, AND the inlet rows are enforced with the inlet velocities prescribed. For a linear pressure p = g x on a uniform mesh the interior nodal sums cancel (the node on the right of one element is the node on the left of the next), but a boundary node row receives only one element: `sum_{inlet nodes} S_i = (alpha/mu) (-g) h^2 H/12 (per unit depth, uniform h, channel height H)`, which with the Poiseuille gradient `g = -12 mu Q/H^3` equals **alpha (h/H)^2 Q**. The prescribed inlet flux then no longer reaches the interior: a mass defect of alpha (h/H)^2 of the flux appears at the inlet column and the opposite-signed sum sits in the unenforced outlet rows. (My first version of this section only counted the constrained rows and missed the inlet rows: corrected.)
(c) Measured: straight channel (h/H = 0.1, alpha = 0.75): flux at x = 2 is 0.99264 Q_in (prediction 1 - 0.0075), outlet 0.99708 (stock: 1.000000 and 1.000002). C1b: flux at x = 1.03 = 0.99224 (cumulative sum of S over the nodes upstream of x = 1.03: -0.00785), x = 13: 0.9802, outlet 0.9845, Q_out/Q_in - 1 = -1.55 % (stock +9.1e-5). In the cavity region the pinned floor-corner rows (unenforced, nonzero S) add a further deficit.
(d) So the term is element-wise zero-sum but NOT conservative for the physical in/out flux with essential velocity conditions on a flux boundary: the loss is first order in alpha and second order in h/H (scaling prediction, only the alpha = 3/4, h/H = 0.1 point measured: NOT TESTED at other values).

## 10. Limit under mesh refinement
`p - Pi p = O(h |grad p|)` pointwise, but the term enters the weak equation only as `(p - Pi p, q - Pi q) <= C h^2 ||grad p|| ||grad q||`: consistency error O(h^2) in the weak (dual) norm, the same order as the Q1 pressure interpolation error and one order beyond the O(h) velocity-energy error expected of Q1/Q1 + PPP. Dimension check: (alpha/mu) h^2 |grad p|^2 relative to mu |grad w|^2 = alpha (h/H)^2 (|grad p| H^2/(mu U))^2/12 -> 0 as h^2 (for the channel: (H^2/(mu U))|grad p| = 12 so relative size 12 alpha h^2/H^2 ~ 0.09 at h = 0.1, alpha = 3/4: NOT negligible at M1, falls 4x per refinement; this is an estimate, to be checked by the Stage-4 smooth-field comparison). As h -> 0 the term vanishes and the formulation returns to the unstabilised one (which is itself inf-sup-deficient there: the stabilisation fixes that deficiency). Observed convergence orders: NOT TESTED (no mesh study authorised).

## 11. alpha = 0
Implementation rule: `if (alpha == 0) return` before any work (no arithmetic added to fe or ke). alpha is read once from the environment variable `FEBIO_PPP_ALPHA` (not a model parameter), so the physical input is unchanged; the value is printed in the log header of every run. The stock arithmetic of fe/ke is then executed unchanged, so a bitwise comparison (or 1e-8 if thread-order differences arise) with the stock binary is possible (Stage 2/3).

## 13. Flux-preserving round (written 2026-10-30 BEFORE any round-2 code was compiled or run). The alpha = 3/4 formulation of sections 1-12 FAILED mass conservation and stays REJECTED.
### 13.1 Exact global balance with and without the term
Steady rows (rate terms vanish at steady state; the argument is identical with them): `R_i = sum_e [C_i,e + S_i,e] + b_i`, `C_i,e = int_e (N_i (grad e_f . w)/Jf + gradN_i . w)` the stock continuity row, `b_i` the inlet flux load `int N_i VN dA` (`FEFluidNormalVelocity::LoadVector`), `S_i,e` the PPP row. Since `sum_i N_i = 1`, `sum_i gradN_i = 0`: `sum_{all i} C_i = int (grad e_f . w)/Jf dV` (a small O(1/K) term) and `sum_all b_i = -Q_in`-type boundary flux, so `sum_all R_i` is the stock global balance (inflow, outflow reaction, volume change). Solver: only free-e rows i in F are solved, `R_i = 0`; constrained rows c in C (outlet `zero fluid dilatation`, 4 pins, 4 rim nodes, all `DOF_FIXED/DOF_PRESCRIBED` e_f) are removed; their value `R_c` is the REACTION, i.e. the outflow through the constrained nodes.
* Without the term: `sum_F R_i = 0` => the outflow reaction `sum_C R_c = sum_all R` = stock balance (flux out = flux in to 2e-6, measured).
* With the term: element-wise `sum_{i in e} S_i,e = 0` (proved, 5e-16 measured) gives `sum_all S = 0`, so the all-row balance is unchanged, BUT the solved system enforces `sum_F (C_i + S_i + b_i) = 0`, i.e. **`sum_F (C_i + b_i) = - sum_F S_i = + sum_C S_c =: L`**. The stock free-row balance is violated by the **boundary leakage `L = sum over constrained rows of the stabilisation term`**. Mechanism: eliminating the constrained e_f rows removes `S_c,e` from the elements touching C, so the free rows of such an element no longer sum to zero (`sum_{i in e, free} S_i,e = - sum_{c in e} S_c,e`). Measured on C1b alpha 3/4: `sum_C S = 0.0179` per unit depth against Q = 1; rim, pins and outlet are the constrained rows; the flux-prescribed inlet nodes are FREE-e rows (their w is prescribed, their continuity row is solved with the load b_i) and do not contribute to L.
### 13.2 Second, independent mechanism: nodal-ramp moment (cut defect)
The flux through a node column is the stock-consistent quantity because for A = nodes with x <= x_j and `q_A = sum_{i in A} N_i`, `sum_A C_i = int gradN.. q_A` is the nodal flux. The term contributes `sum_{i in A} S_i = -(alpha/mu)(p - Pi p, q_A - Pi q_A)`. On elements where q_A = 1 this is 0 (zero element mean); on the single element cut by the node column q_A = ramp, and for p = g x (uniform mesh, height H, unit depth): `(p - Pi p, N_left) = -g h^2 H/12`, so `sum_A S_i = alpha g h^2 H/(12 mu) = - alpha (h/H)^2 Q` with g = -12 mu Q/H^3, **the same for every cut j** (telescoping), and also for j = 0 (inlet column). So `Q_j = Q_in (1 - alpha (h/H)^2)` in the interior; measured 0.99264 at alpha = 3/4, h/H = 0.1 (prediction 0.9925).
**Why it cannot vanish for any element-local P0 projection:** the kernel of `p - Pi p` is the set of element constants; linear p (Poiseuille) is not in it, and the diagnosed y-parity mode is itself element-wise linear (+a on row 0, -a on row 1), so any local operator that annihilates linear p also annihilates the mode and stabilises nothing. The defect is the consistency error of the term, `|sum_A S| <= (alpha/mu) ||p - Pi p||_{cut} ||q_A - Pi q_A||_{cut} = O(alpha h^2 |grad p| H/mu)` (h^2 weak consistency, as in section 10), exactly alpha (h/H)^2 Q on Poiseuille. It can only be made small by alpha and h, not removed.
### 13.3 Candidates, analysed by mathematics
* (a) equal-and-opposite redistribution of the constrained rows: `S~_i = S_i + (1/nF) sum_{c in C_e} S_c` (i free), `S~_c = 0`. Then `sum_{i in e free} S~_i = 0` exactly for every element (also the sum over all rows of the element, since `S~_c = 0`), hence `sum_F S~ = 0` and `sum_all S~ = 0`: **L = 0 exactly**, mechanism 13.1 removed. The map P is linear and constant (equal weights: independent of e and x), so tangents are `P` applied to the rows of the old tangents (including d/du). Consistency: each moved contribution is O(h^2 |grad p|) like the term itself; no new order. It is a pure internal redistribution among the free rows of an element. Does NOT remove 13.2 (interior cuts keep the defect alpha (h/H)^2 Q, the outlet section recovers, since sum_F S~ = 0 makes the last cut exact).
* (b) delete/modify the term on rows of the flux-prescribed inlet nodes: for the uniform linear Poiseuille field the inlet-row sum equals the same -alpha (h/H)^2 Q and its deletion cancels the interior defect, but this is special to uniform p: in general `sum_all S~ = - sum_inlet S != 0`, the all-row balance is destroyed and the consistency (zero-mean per element) is lost. Not accepted: not proven consistent.

### 13.4 Consequences for the Poiseuille exact solution (predictions, written before the run)
With (a): interior sections `Q_j = Q_in (1 - alpha (h/H)^2)`, last section and outlet exact (to the 1e-6 of the stock), pressure gradient `-0.12/(1-h^2) * (1 - alpha (h/H)^2)`. The defect does not vanish; it is O(alpha h^2) and is controlled by alpha. It is therefore the choice of alpha that must satisfy a pre-registered tolerance; alpha is chosen from stability, not from results.
### 13.5 alpha for round 2 (predeclared from the operator spectrum, no run, no force)
Stability needs the stabilised parity eigenvalue (about alpha/mu, since (M - M_Pi)/M ~ 1 for an element-zero-mean mode) to exceed the lowest SMOOTH Schur eigenvalue of the unstabilised operator (`b4_modal_scaling.json`, straight channel h = 0.1: 0.1045; parity family 1e-3), i.e. `alpha = mu * lambda_smooth,min = 0.01 * 0.1045 = 1.0e-3`. This lifts the soft family from 1e-3 to about 0.1, the scale of the smooth spectrum (a ~100-fold reduction of the forced parity amplitude in the linear estimate), and gives the predicted defect `alpha (h/H)^2 = 1.0e-5` (< 1e-4). **alpha = 1.0e-3 is the only alpha of this round.** (The earlier 3/4 matched the continuous upper bound; that value is retained only as the rejected case.)
