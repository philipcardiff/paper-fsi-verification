# CAVITY FORCE DEFICIT: DECISION (CAVITY agent, task B4, 2026-10-30)
Inputs: `CAVITY_REFERENCE_FIELD_INVENTORY.md` (B1), `CAVITY_SOLVER_FIELD_COMPARISON.md` (B2, B3). Nothing was run; no job submitted; no PR, comment or push; no manuscript or ring file touched.

## 1. Decision: **C. No new calculation until a reference field exists**, with the one cheap data-acquisition run on the reference side prepared as a proposal.
Not A, not B. Reasons, in order of weight.

**Why not B (corrected FEBio pressure-boundary test).** The rule was "only if a definite physical mismatch has been demonstrated". None has: outlet datum, underside loading, rho, mu, Re, inlet flux, no-slip walls, depth normalisation, geometry and solid law are all verified equal or differ by amounts that cannot produce 5 % (B1 table: the inlet discretisation differs by at most 1 %, the corner pins by 0.1-0.4 % with the wrong sign). What the data do show is a *numerical* feature of the FEBio nodal pressure (y-parity alternation, sec. 2), which is not a boundary-condition mismatch and cannot be tested by changing a boundary condition.

**Why not A (matched fixed-geometry fluid calculation in both solvers).** The half that would be run in FEBio already exists: C1b is a fixed-plate fluid-only run at M1 (raw F_y -4.6637, pair-mean row force -5.4833, y-parity D = 0.415 Pa, `cavity_agent/b2/ybranch_C1b_fixed_M1.json`), and the finding of sec. 2 is already a fluid-only property (present with the plate fixed, absent in a straight channel). A new FEBio fixed-geometry run (M2: 4 cores, about 25-30 min, about 2 CPU-h, as recorded in `CAVITY_NEXT_DECISION.md`) would not add information until a solids4foam field to compare with exists; and once that exists, the coupled M2 fields FEBio already has (`runs/cavityNext/C3_fsi_M2`) can be compared directly. The deformation is not the cause (deflection difference changes F_y by <= 0.04 %, B2 sec. 8), so a fixed-geometry pair is not needed to separate cause from consequence either.

**Why C.** The deciding observable is a number that is absent from every retrievable source: the solids4foam floor p(x) at M2. Every existing FEBio analysis has been exhausted (reconstruction, pins, x-parity, viscous, steady state, momentum balance, plate transfer). A solids4foam M2 field-output run costs about 0.1-0.25 CPU-h serial (proposal `cavity_agent/proposal_s4f_M2/`, not run) and is the most informative single action; it belongs to someone authorised to run OpenFOAM, or to a request to the maintainers for the existing `rf-cav-qm-L2` fields (the maintainers' HPC system `(maintainers' HPC run directory, not committed)

## 2. Evidence that frames the decision (numbers from B2/B3)
- Gap vs solids4foam QM / Tukovic / ANSYS at the same dx, raw FEBio F_y: -7.9 / -5.6 / -5.1 % (QM); the references agree among themselves to 0.2 % (COMSOL 0.7 % at the finest meshes), so the force reference is supported by three independent codes.
- Standard suspects are small: pins 0.41/0.19/0.10 %, x-parity bracket +/-3.0/0.4/1.0 %, viscous 0.03 %, M3 incomplete steady state 0.007 % (decaying plate mode, e-fold 86 s, period 44 s, same at all levels), K/dt/tolerance nil (C4), deformation difference <= 0.04 %. In the most favourable direction the raw force stays 4.0-5.0 % below the references.
- **New**: the nodal pressure in the cavity alternates row by row (D = 0.363/0.171/0.134 Pa), the interface row lies on the low branch, and the mean of the first two rows (= FEBio's own element pressure of the wall-adjacent elements) gives F_y -5.437/-5.275/-5.249 vs QM -5.1226/-5.2266/-5.2504, i.e. +6.2/+0.9/-0.02 % (Tukovic, ANSYS, COMSOL: same within 0.9 % at M3), plate-only u_y(A) -0.2393 (corrected to 40x4) vs -0.2382/-0.2384, u_x(A) 1.6e-4 (raw 3.8e-4, solids4foam 9e-5, ANSYS 8e-5). The mode is deterministic (identical for dt/2, K x10, tolerance), independent of coupling (fixed plate too), and absent in a straight channel. B3 shows the vertical momentum balance cannot detect it: at M1 the mouth line lies on the opposite branch and the cavity balance fails by 31 %, at M2/M3 it closes to 0.03-0.08 % only because floor and mouth share a parity.
- Status of that finding: **hypothesis, strongly supported by existing data, not proven** (found after the gap was known; M1 overshoots 6 %; mechanism unknown; solids4foam pressure field unseen). It is *not* applied to any reported number; all FEBio F_y and u_y values stay raw.
