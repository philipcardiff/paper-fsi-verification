Status: corrections required by the INTERNAL AI audit `COUPLED_AUDIT_D.md` (verdict QUALIFIED, section 9) plus items found while preparing the supplementary draft (marked NEW). `COUPLED_RESULTS.md` itself is left unchanged (it is the record of what was reported); where this file and COUPLED_RESULTS.md disagree, this file governs. ## Section 1 (spatial study)
1. Mass defect. "absolute and normalised peak 7.80e-4 / 7.84e-4 of |Q_in| = 1" is wrong. The absolute peak is 4.15e-4 to 4.16e-4 (step 2, all levels, |Q_in| = 1). 7.8e-4 (7.80e-4 to 7.84e-4) is the value normalised by the instantaneous inflow at step 1, where the inlet ramp gives |Q_in| = 0.5. The defect still equals the closed-form BE geometric defect to 5e-13 and the steady-state value is <= 4.4e-13.
2. "L4 differs from the extrapolation by ... 6e-4 % (F_y)" is wrong: 1.7e-4 % (relative 1.7e-6). u_y: 0.042 % is correct. "0.1 % between L3 and L4 in u_y" is wrong: 0.061 %.
3. Support-reaction order "p = 0.97" is an artefact and is withdrawn. The reported R_left/R_right exclude the clamp-corner nodal force; the deficit R_left_y + R_right_y + F_y = -0.04745, -0.02393, -0.01212, -0.00615 (L1-L4) halves with every level (ratios 1.98, 1.98, 1.97), i.e. it is proportional to dx. No order is reported for the reactions.
4. u_y order. About 1.3 and pre-asymptotic: the order drifts down with refinement (1.37 on L1-L3, 1.28 on L2-L4), the asymptotic range is not demonstrated, and no sentence may say second order for u_y. If p were anywhere in [1,2] the limit would change by -0.018 % to +0.022 % (about the size of the GCI 0.053 %). The F_y order 2.18 rests on a single accepted triple (L2-L4); L1-L3 gives p = 3.0002 (not accepted).
5. NEW. u_x(A): "+0.8 %" is imprecise. Against the strict partitioned sequence: +0.86 % at the finest level and +0.66 % between limits (9.688e-5 against 9.624e-5).

## Section 2 (error classes)
6. Pseudo-time stop error. The steady criterion (relative rate < 1e-6 per s for three steps) leaves u_y increments ringing at about 1e-6 m (about 5e-6 relative; L2 last eight increments -8.0e-5, -4.8e-5, -6.8e-6, +9.3e-6, +7.7e-6, +2.1e-6, -8.5e-7, -1.1e-6 m), the same on all levels to 2 %, so it cancels in level differences. "Steady" means steady to about 5e-6 relative, not machine-steady.
7. "Reference-model uncertainty: ... Tukovic/ANSYS/COMSOL laws unverified" is stale. The paper records ANSYS (3-D slab) and COMSOL (2-D) as linear elastic with geometric nonlinearity (paper PRs 12, 20, 22; COMSOL is StVK in intent, plane strain or stress not stated, load about 0.7 % higher); the Tukovic law is not confirmed. No equivalence between Tukovic, ANSYS or COMSOL and the exact model is claimed.
8. Conservation gates (interface-velocity, power, force balance, mass closure) are algebraic identities of the monolithic form with a shared test function: they certify internal consistency, not physical correctness.

## Section 3 (M2 labelled sensitivity)
9. "Converged, same gates" is wrong. For the M2 run the relative balance residual peaks at 1.3e-2 (8.7e-3 at stop, absolute 0.099) against the gate G4 <= 1e-8. This is expected by construction: M2 loads the plate with sigma_f n_hat per reference area while the assembled fluid force is sigma_f a (a = J F^-T N), so it is not force-conservative. G4 is not applicable to M2. The power gate G5 still holds (7e-13).
10. M2 is a labelled sensitivity measure and is NOT the cavity tutorial's transfer. Source reading (solids4foam 669d0f58d): `nonLinGeomTotalLagTotalDispSolid.C` lines 251-384 and 480-500 build forceP = (traction - nCurrent p) * magSfCurrent (traction times CURRENT face area, `useUndeformedArea` false by default and not set in the tutorial `0/solid/D`), the Nanson-consistent M1 measure. The earlier "tutorial = M2" came from the linear-geometry solid path (blob case). No solids4foam run was made here to test applied against fluid-reported force.
11. Preregistered prediction (b) ("M2 changes |u_y| by +0.3 to +1.2 % and moves it toward R") rested on that false premise and is WITHDRAWN as ill-posed (not "partially failed"); its failure is kept: the size part holds (+1.04 %), M1 is already within 0.05 % of R and M2 moves 1 % past it. The text "either the tutorial transfer is closer to M1 than assumed, or the effects cancel; cannot be decided" is replaced by the source finding of item 10. The preregistered band text "agrees within the expected formulation band (the tutorial uses the M2-type transfer)" is void for this case.
