# cavityFlexibleBottom: second implementation (FEniCSx), exact StVK plane-strain model

Status: **draft supplementary evidence. A second implementation by the same research group and tooling lineage; not an independent verification and not externally reviewed.**
Text: `../../supplement_fenicsx_cavityflexiblebottom.tex` (build alone with `latexmk -pdf supplement_fenicsx_cavityflexiblebottom.tex`; 9 pages including references; it cites `Baratta2023` (DOLFINx), added to `bibliography.bib` here byte-identically to PR #69 (merge-tested in both orders), plus `PETSc`, `MUMPS:1`, `MUMPS:2`, `Tukovic2018` already in main).
Layout follows `paper-data/fenicsx_blobintreacle/` of PR #69. Related cavity work in the paper: PRs #12, #14, #18, #20, #22, #23, #27, #67.

## Reproduce the derived tables and figures
Use `python3 -B` (or `PYTHONDONTWRITEBYTECODE=1`) so that no `__pycache__` is left behind (also ignored by `.gitignore`).
```
cd paper-data/fenicsx_cavityflexiblebottom
python3 -B -I scripts/analyze_cavity.py    # derived CSVs, byte-identical to the committed ones
python3 -B -I scripts/make_figures.py      # needs numpy and matplotlib
sha256sum -c SHA256SUMS
python3 -B scripts/extract_from_raw.py COUPLED_DIR C1_DIR data   # needs the solver repository (optional)
```

## Review lineage
Code written and run by AI agents of one model family (coupled campaign "C2", plate-only and fluid-only preflight "C1", reference audit) for the same research group; one internal AI audit ("Agent D", same lineage, not external or human; verdict **QUALIFIED**, `AUDIT_INTERNAL_AI_D.md`); a second internal AI gate of the draft (same lineage, QUALIFIED) required edits E1-E14, applied in later commits of the branch: numbers verified against raw data, no numerical error that changes a conclusion, nine required text edits (applied in the supplement; `ERRATUM_COUPLED_RESULTS.md`). The audit's required restrictions on wording: no "independent verification" (second implementation by the same group and tooling lineage); u_y order about 1.3 and pre-asymptotic, never second order; F_y order 2.2 on a single accepted triple; no equivalence among Tukovic, ANSYS, COMSOL and the exact model; the labelled sensitivity is not the tutorial's transfer; the reference variant, its dt and steady criterion named whenever agreement is quoted.

## Retained failed, cancelled or excluded runs
- `scan_L1_dt20` (job 16651): SNES diverged at the first step (pseudo-time step too large); kept as the upper bound of the usable step.
- `rigid_L1_stiff` (E x1e7, job 16652): converged for 14 steps (agreement 1.6e-9 with the frozen floor), then SNES failed at step 15 (reason -5); attributed by the authors to roundoff at a stiffness ratio of 1e9 (not shown); the E x1e5 run (job 16658) is the rigid-limit result.
- `cavgeo_L1`-`cavgeo_L4` first attempts (jobs 16623-16626, ledger FAIL): script errors in the geometry check (empty-array reduction, then a singular harmonic matrix), fixed; valid geometry jobs 16627-16632.
- `cavpre_analytic` first run (job 16639, ledger FAIL): the test compared a weak force that excludes the clamp-corner dofs; the test was corrected, the physics unchanged (valid run 16646).
- `cavscal_L3_n8` (job 16657): cancelled while pending (16-core budget); the L3/L4 cost estimates were therefore extrapolated from L1 and L2 and checked afterwards (L3 0.83, L4 5.85 CPU-h against estimates 1.0 and 6).
- Graded-mesh corner experiment, jobs 16716 and 16722 (`c1_corner`, `c1_corner2`): all graded cases with nt >= 8 diverged; both ledger rows FAIL; kept (see the section above).
- C1/C2 `svktests` jobs (within 16633-16647): the first (driver imported `slurm.driver_exit` before `sys.path` held the root, no test run, ledger FAIL), the second (EXIT wrongly OK after 2 s: the child python inherited the mpiexec PMI environment and aborted in MPI_Init, and the failure was silently ignored because of a second module instance); the third scrubs PMI variables and is the valid run. Lesson recorded: EXIT OK from those drivers is necessary, not sufficient; the converged flags were checked.
- No production run failed.

## What is not claimed
No independence (different group); no second-order convergence of u_y (order about 1.3, pre-asymptotic: limit moves by -0.018 % to +0.022 % for p in [1,2]); F_y order 2.2 on a single accepted triple; no equivalence of Tukovic, ANSYS or COMSOL with the exact model; the sensitivity measure is not the cavity tutorial's transfer; conservation gates are consistency checks (algebraic identities of the monolithic form), not proof of physical correctness; agreement with solids4foam only within the spread of the reference variants and their GCI (0.29 %); the solids4foam values are legacy moving-wall BC (solids4foam #671 changes `newMovingWallVelocity`): the cavity floor stretches little (0.78 % mean stretch; viscous part 0.03 % of F_y); floor stretch is not evidence about the #671 effect: no estimate of the #671 effect exists and it is NOT verified, reruns pending; the cause of the u_y order is not tested; the outlet-form difference to the tutorial is quantified on a rigid floor only.

## Known open points
Single mesh family; one level for the sensitivity run; the clamp-singularity reading of the order is plausible but untested; solids4foam strict sequence has dt halving with dx, damping 0.1 and a vanishing stabilisation term and a 1e-4 plateau criterion; the solver repository is not public; no review by a human outside the lineage; the `.msh` files are not archived (hash-checked regeneration only).
