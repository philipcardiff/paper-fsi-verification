# radialTorsionalRing study material

This is the full study material of the `radialTorsionalRing` benchmark (pfv
#25), moved out of the solids4foam tutorial (solids4foam PR #637) so that the
tutorial stays lean. It is copied unchanged from solids4foam commit
`96b468e5c`, the PR head before the move.

- `tutorial_README_96b468e.md`: the long tutorial README at that commit, with
  the scope and claim boundaries, the numerical-acceptance tables, the
  time-step and strict-coupling checks, the independent evidence for the
  reference and the normal-wall-stress analysis.
- `verification/`: the two-layer acceptance driver (`scripts/verify.py`,
  `acceptance.py`, `family.py`, `status.py`), `thresholds.json`, the 138
  tests without CFD (`test_verify.py`) and the rigid-ring Stokes-layer check of
  the reference. The generator, reference and analysis scripts here are the
  versions the driver was written against; the tutorial keeps its own copies.
- `figures/`: Figures 1-3 of the PR description, their data and scripts.
- `system/fluid/fvSchemes.gaussPressure`: the Gauss linear `grad(p)` variant
  that removes the combined error floor.

## Validity

All results here predate solids4foam #671 (merged 2026-11-07), which made
`newMovingWallVelocity` use a continuity-based wall-normal velocity gradient
by default. They therefore correspond to `continuityNormalGradient no`. The
normal-wall-stress analysis (about one third of the reference transmitted) is
the defect that #671 addresses; the radial and combined results, and the
normal-traction quantities in particular, need to be rerun on a build that
includes #671.

`family.py` fingerprints the dictionaries and the coded function-object
source of the cases. The tutorial dictionaries were reformatted in #637
(solids4foam banner, expanded entries, restyled coded C++, with byte-identical
diagnostics output), so this driver will probably not recognise cases
generated by the current tutorial until its fingerprints are updated (not
tested).
