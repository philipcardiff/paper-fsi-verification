# Addendum 2 to PREREG_NH_BLOB.md (written and hashed BEFORE the runs; the A1T result was already seen)

Observation: A1T (SNES rtol 1e-12, atol 1e-13) reproduced the main T series to <= 6e-13 relative in every observable (u_x(1) at all six dt), so the stagnation of the successive u_x changes (orders 2.02, 3.09, 1.21, 0.63) is NOT a nonlinear-solver tolerance floor: it is deterministic behaviour of the discretisation. Candidate causes (none established): the single backward-Euler first step of the BDF2 start-up (OpenFOAM `backward` behaviour, matched to s4f), the ALE mesh-velocity/geometry treatment, the time-lagged solid velocity-displacement coupling, or interaction of several error terms of different sign.
Test (one factor): repeat the six T runs with the first step done as 16 backward-Euler substeps (`--startup-substeps 16`, the existing `step_bdf2_startup` already used by the earlier BDF2 studies), everything else identical (x1, dt = 0.25 ... 0.0078125, t_end 1, 2 ranks, default SNES tolerances). Labelled A2T; estimated 0.12 CPU-h. This is a diagnostic of the FEniCSx time discretisation, NOT a match to the s4f scheme (s4f starts with a single Euler step), and it replaces nothing in the main time study.
Prediction (recorded now): if the single BE first step is the dominant first-order contribution, the u_x changes of A2T scale with order ~2 (all pairs in [1.6, 3.0]) down to the finest dt; if the orders stay as in the main run (differences between A2T and T of the order of the late u_x changes, 1e-5), the start-up is not the cause and the cause is left open. Either way the observed orders are quoted as found; no order claim is made for pairs with orders outside [0.5, 3] under `analyse`.
