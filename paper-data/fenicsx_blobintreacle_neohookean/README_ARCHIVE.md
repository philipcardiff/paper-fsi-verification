# Archive package description (Zenodo-ready; NOT published, no DOI minted, no authorship assigned)

**Raw data and the solver repository (`fenicsx-fsi-verification`) are not public. Reproducing the tables from this repository alone is possible for the derived CSVs, the figure and the checksums (from the input CSVs in `data/`); re-extracting the FEniCSx and Phase 0 input CSVs needs the evidence archive below, and re-running the solver needs the private repository.**

Description (for the record): *Same-lineage cross-code check (FEniCSx, DOLFINx 0.10.0) of the finite-strain neo-Hookean blobInTreacle benchmark (solids4foam PR #694): monolithic ALE results on four spatial levels and six time steps, preregistration with two addenda, Phase 0 constitutive and solid-only gates, solids4foam reruns at the pinned head, an internal AI audit and the response to it. Same group and tooling lineage as the reference runs; not an independent validation.*

## Evidence archive (outside git; nothing uploaded)
`nh_evidence_2026-11-10.tar.gz`: 555 files, 1 898 547 bytes, **sha256 `54325c40707cbdcce34f50fb26cbae6b0410c025d54e19cb0045ec7e98d44016`**, root directory `nh_evidence/`. Built with `tar --sort=name --owner=0 --group=0 --numeric-owner --mtime=@0` and `gzip -9n` (two builds gave the same sha256). Per-file sha256 of its contents: `ARCHIVE_MANIFEST.sha256` (this directory). Raw run records and some solver files in it contain local absolute paths, and the internal result notes in it predate the decision to publish the neo-Hookean results as a separate supplement (they contain a different recommendation for where to place them, and wording about the state of an earlier response); they are kept unedited as records and are **not** part of the repository text.
