# Archive package description (Zenodo-ready; NOT published, no DOI minted, no authorship assigned)

Purpose: a public archived snapshot of what the hand-transcribed CSVs and scripts in this directory cite, required before journal submission.

## Snapshot to archive
1. This directory (`paper-data/fenicsx_blobintreacle/`) at the commit that is merged.
2. The solver repository `fenicsx-fsi-verification`, whole, at a tagged commit (the CSVs here cite commit 0fe2a15 and the report hashes in `data/SOURCES.md`; the tag must be at or after the commit containing the reports cited, and any untracked run directories, `runs/a1_*`, must be committed first). Not yet public; location and licence to be agreed.
3a. solids4foam build records of the #671 rerun (`s4f_side/w671/BUILD_INFO_*.txt`, commits list, provenance); the proposed branch is unmerged and is not an official release (head da1044a4f, base 6a49bf0a91).
3. Frozen code commits used by the runs: c8a4b0a, 1484d94, 6f85a48, d17df8b, 9f4b6e8, 722429d (solver repo); solids4foam 1576edcc4 with the E-AREA user library (`s4f_side/lib`).
4. Environment lock (`environment/environment_explicit_lock.txt`) and the four mesh files (sha256 in README.md).
5. Not included by default: raw `history.csv` of every run (size); include if the archive limit allows.
