## 0. Facts the plan rests on (with what changed after the independent temporal audit, commit 1b46be4)
- Wall velocity seen by the fluid (the audit's key point). In this solver the interface (no-slip) velocity u and the ALE mesh velocity w are the SAME BDF2 first derivative of the displacement, u = (a0 d + a1 d_n + a2 d_{n-1})/dt (BE on step 1), enforced by the kinematic rows on the wall cells; the wall inertia is BDF2 applied once more to u (a = (a0 u + a1 u_n + a2 u_{n-1})/dt), i.e. "BDF2 applied twice" = the solids4foam `backward` d2dt2 operator (verified: backwardD2dt2Scheme.C, coefft/coefft0/coefft00 form, uniform-dt equivalent (2.25,-6,5.5,-2,0.25)/dt^2; the (2,-5,4,-1) formula used as "bdf2" in COL-1's svk_dynamic.py is NOT the s4f operator: COL-1 mislabel, flagged). s4f's wall velocity seen by the fluid, verified in newMovingWallVelocityFvPatchVectorField.C: Up = coefft (Fc - oldFc)/dt - coefft00 (oldFc - oldoldFc)/dt, i.e. the same BDF2 derivative of the interface position (deltaT0 = GREAT, hence BE, on the first steps). oomph: the fluid mesh/BDF<2> node time stepper and an auxiliary no-slip update on the wall nodes (driver lines 456-510, 700-712 read; the library function apply_no_slip_on_moving_wall is U: assumed to use the node (fluid BDF2) time stepper). So the primary FEniCSx definition matches the s4f source and (U) oomph.
- The solid time scheme is NOT irrelevant. The audit's 1-DOF Duffing model: replacing the BDF2 wall velocity by a trapezoid (Newmark-like) velocity changes the first trough by ~0.6% P at dt 0.025, 0.15% at 0.0125, 0.04% at 0.00625. The wall-inertia term alone is ~0.1% of the modal mass (added mass ratio 660-1050 for mode 1), but the kinematic route is multiplied by the fluid. Therefore: (a) variant WV (controlled, section 3, FM-W): wall velocity by trapezoid at the interface AND in the ALE velocity; code item to be added and tested (mass/GCL) before it is run (NOT in the current solver: the option "newmark" changes the wall INERTIA only and keeps the BDF2 kinematics: it is a different, weaker variant, labelled FM-N); (b) no statement that the solid scheme is irrelevant is preregistered; prediction below.
- Temporal error mechanism: period elongation (dispersion) in the forced response, not numerical damping (audit 1.5: a forced Duffing oscillator with BDF2 reproduces the full oomph deficit pattern 1.48/0.38/0.09/0.02% P). The hypothesis "the 0.5% same-dt floor is temporal truncation" is DISFAVOURED (the floor equals oomph's own temporal error at dt 0.00625; s4f and oomph temporal errors are common to ~10%, so at most 0.05-0.1% P of the floor can be scheme mismatch) and is NOT the expected outcome.
- Reference values: oomph first trough -0.21600 (U_ref 0.30% P, spatial bias 0.26% unremoved); oomph same-dt first-trough deficits (interpolated trough, V audit 1.5): 1.40, 0.375, 0.125, 0.019% P at dt 0.025, 0.0125, 0.00625, 0.003125; model-free trough differences go as p = 2.0 then 1.2-1.3 (both codes): NO second-order rate is predicted. The composite s4f limit (-0.2164..-0.2166; Aitken p~1.3: -0.21605; additivity untested) is an estimate and enters NO acceptance criterion.
- Time structure of the reference history: main line ~1.5 Hz (period 0.652 s), harmonics 3.2-3.4 Hz (~3.3% P at the quarter points, 20-35% attenuated at dt 0.025), lines 5.2/6.8/8.4 Hz at the quarter points (0.65/0.43/0.14% P), bounds <= 0.1% P at 15 Hz and <= 0.02% P at 26 Hz (fourth-difference, dt <= 0.00625). "Dry mode not visible" is not modal evidence (mid-wall is blind to antisymmetric modes; Nyquist 20 Hz at dt 0.025).

## 1. Hypotheses (predictions, falsifiers). No hypothesis uses -0.2164
H1 (spatial, two-factor with H2): the pointwise first-trough value V1 (x = 7.5, 10, 12.5, bottom face) at dt = 0.00625 changes S1->S2 by 0.5-3% P and S2->S3 by 0.1-0.5% P; observed order is reported only if analyse accepts (>= 3 monotone levels, p in [0.5,3]); wall-along error is expected at p ~ 1.3-1.5 (corner singularity, Q2 history; NOT assumed for P2 triangles, the order is measured). Falsifier: non-monotone V1.
H2 (temporal): FEniCSx first-trough deficits relative to the FEniCSx dt->0 limit follow the oomph/s4f same-dt pattern (-1.4, -0.38, -0.125, -0.02% P at dt 0.025, 0.0125, 0.00625, 0.003125) within +-0.2% P (dt 0.025), +-0.1% (0.0125), +-0.05% (finer); the model-free trough differences go as p ~ 2 then ~1.2-1.3 (not predicted to be second order throughout). Falsifier: deficits differing from the pattern by more than the tolerance means the temporal operator differs from s4f/oomph (kinematic route, startup): investigate before stage 2.
H2x (separability / cross term, the decisive design change): factorial {S1,S2,S3} x {dt 0.0125, 0.00625, 0.003125} (corners {S2,S3} x the three dt at minimum, S1 added because it is cheap). Cross term X(dt) = [V1(S3,dt) - V1(S2,dt)] - [V1(S3,dt/2) - V1(S2,dt/2)] and the analogous time-difference cross term. Additive if |X| <= max(0.05% P, 0.25 x min(|space effect|, |time effect|)); only then are independent space and time extrapolations allowed; otherwise report the 2x2 / 3x3 table and quote only the finest-cell value with an uncertainty equal to the largest neighbouring difference, no limit.
H3 (reference agreement): the FEniCSx limit (only if H2x additive and analyse-accepted) agrees with the oomph reference (-0.2160) within U_ref (0.30% P) + U_mf (0.15% P, COL-2, unresolved) + U_FE (U_FE = max(GCI_fine(space), GCI_fine(time), last change)); 0.5-1.0% P after U_FE = ambiguous (no attribution), > 1% P disagreement. Attribution of the s4f 0.5% floor to s4f only if the FE limit agrees with oomph by that criterion AND |s4f finest(time-corrected, with its Aitken-range uncertainty) - FE limit| > 2 x combined uncertainty; no attribution from equal-dt differences.
H4 (formulation, diagnostic): (a) FM-N (Newmark wall inertia, BDF2 kinematics) changes V1, V2, V3 by <= 0.05% P at dt 0.0125 and 0.00625 (weak variant: expected small because the kinematic route is unchanged); (b) FM-W (trapezoid wall velocity in the interface and ALE) changes V1 by 0.1-0.2% P at dt 0.0125 and ~0.5% P at dt 0.025 (audit 1-DOF model: 0.15% / 0.6%): a change < 0.05% P at dt 0.0125 would falsify the audit's kinematic-route argument; (c) fluid first-order BE (FM3/FM4) changes V1 by > 1% P at dt 0.00625 (positive control).
H5 (end conditions): natural-traction vs Dirichlet-p/zero-gradient (FM5, implemented as ends="dirichletp": strong p at the end nodes removes their continuity rows, so FM5 does NOT conserve mass exactly: measured q-sum 4e-3 in a 20-step smoke vs 1.6e-10 for the primary; the mass criterion is waived for FM5 and its q-sum is reported; at t = 0.25 FM5 and the primary agree to 5e-8 m in wall displacement) changes V1-V3 by <= 0.15% P (> 0.3% P is a model-defining finding).
H6 (model form, coupled): beam-minus-continuum open-loop replay gap (MF1) <= 0.15% P; else MF2 (coupled beam) or the comparison is declared limited by model form (the static agreement is not evidence).
H7 (tolerance): strict vs default Newton tolerance changes V1-V3 by <= 0.02% P; loose is a positive control (accuracy cost reported).
H8 (coupled load, FEBio-mechanism): no wall-normal pressure parity mode (A_par/p_wall <= 3%, expected <= 1e-4); F1/F2/F3 load spread <= 3%; mass conservation (q_in + q_out + q_wall) <= 1e-9 (measured 1.6e-10) and the BDF-GCL residual (q_in + q_out + dV/dt BDF2) reported (time-truncation level, scales as dt^2: M: 7.8e-6 relative at dt 0.0125, 4x smaller at dt/2); assembled wall force balance; min J >= 0.4.
