# Archive package description (Zenodo-ready; NOT published, no DOI minted, no authorship assigned)

**Raw data and the solver repository (`fenicsx-fsi-verification`) are not yet public. Reproducing the tables from this PR alone is possible only for the derived CSVs, figures and orders (from the input CSVs in `data/`); re-extracting the inputs from raw output or re-running the solver is not possible until the Zenodo snapshot exists.**

Description (for the record): *Same-lineage cross-code check (FEniCSx, DOLFINx 0.10.0) of the collapsibleChannel benchmark: monolithic ALE results of a plane-strain St Venant-Kirchhoff wall on three spatial levels and four time steps with preregistered hypotheses, formulation controls, an open-loop beam-versus-continuum replay, comparison with the oomph-lib reference and the solids4foam mesh-study series, preflight studies, an internal AI audit and its corrections. Work by the same group and tooling lineage as the reference runs; not an independent validation.*
