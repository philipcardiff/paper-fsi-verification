# Overnight-2 preregistration B2 (exploratory addendum): pin-value sensitivity at level 1.5

Hashed before the runs. Context: the first B-stage result (level 1.5, pinned, 18,606 cells) gave an F1 drag error of -0.83 % and a lift error of +13.7 % against the Featflow reference, against +15.73 % and +157 % at level 1 (8,330 cells). The two root-junction pins differ strongly between those runs (level 1: -81.6 and -123.9 Pa, derived from contaminated neighbour pressures; level 1.5: +9.9 and +4.5 Pa), so the improvement is confounded with the pin values. This addendum separates the two.
Runs (level 1.5, the C2p_f1.875 configuration, only the two pin values change): P1 = level-1 pin values (-81.6042, -123.8709 Pa); P0 = both pins 0 Pa; P2 = twice the level-1.5 rule values (19.7997, 8.9196 Pa).
Prediction (the stage-C C7 criterion, retained): if the pins are immaterial, the F1 drag changes by at most 0.3 % of the drag between any two variants and the lift by at most 2 % of the lift.
Interpretation rule: if any variant changes F1 drag by more than 0.3 %, the L1-to-L1.5 improvement is reported as partly pin-driven and the statement 'F1 converges under refinement' is limited to the pin-controlled comparison (same pin treatment at the levels compared). The primary preregistered claims B1-B4 are evaluated on the rule-pinned runs as registered. Role: exploratory; budget 1 CPU-h.
