# Parity and load definitions (as implemented in `scripts/cc_f1_analyze.py`, `scripts/cc_fsi_analyze.py`, re-implemented in `scripts/reverify.py`)

Wall rows: row 0 = the interface (wall) nodes at y = 1 (deformed), row 1 and row 2 = the first and second fluid node rows counted from the wall into the channel (row spacing 0.0625 m). p = -K e_f (kinematic = Pa because rho = 1; e_f is the logged nodal fluid dilatation).
- **F1 (applied nodal load; reconstruction from the logged nodal pressure)** = sum over interface facets of the facet-linear nodal wall pressure, (p_a + p_b)/2, times the facet vector. This is the pressure part of the load that FEBio's `fluid-FSI traction` is understood to apply (nodal pressure of the facet; source-level statement from the earlier campaign, see PR #27/#28 packages; the free-body test in `RESULTS.md` section 3 supports it for this case).
- **F2 (element-mean reconstruction)** = the same sum with the mean of the four nodal pressures of the adjacent fluid cell (rows 0 and 1) instead. It is a reconstruction; it is not established as the physical force.
- **G** = first-mode generalised load = sum of p x phi(x) x dx over facets, phi = (1 - cos(2 pi (x - 5)/10))/2 (clamped-beam first-mode shape; the trough is sensitive to it). Relative spreads (F1 - F2)/F2 for F_y and G are the quantities of the force gate.
- **Streamwise parity** a_t = rms over interior wall nodes (3 facets excluded at both ends in F1; 4 in D1) of (p_k - (p_{k-1} + p_{k+1})/2)/2 (along x on a given row). V = max - min of the wall-row pressure over the same interior nodes (smooth variation, 3.51 Pa in F1).
- **Wall-normal row parity** D = p_wall - 2 p_row1 + p_row2 (second difference across the first three node rows). It is this quantity (not a_t) that detects the mode; a_t cannot see it (a gap in the pre-registered definition, acknowledged in the plan; row 3 was not logged). A smooth field gives D near zero (the physical cross-row pressure variation is about 0.3 Pa, estimated from rho a_y h); D of 1-2.7 Pa (F1) and up to about 250 Pa (D1) is therefore not the smooth field.
- Mass balance: Q = trapezoid of the nodal w_x over the end columns, per unit depth; Q_out/Q_in - 1. Volume balance (D1): cumulative trapezoid of (Q_in - Q_out) dt against the area change integral(u_y dx) of the interface.
- Free-body identification: p_f = p_ext - p_el(u_mid) + rho_s h c u'' (stored sign p_el + inertia - p_ext), p_el(u) the uniform-equivalent restoring pressure from the S1 320x8 static curve (20 load steps), c = integral(psi^2)/integral(psi) the shape factor, psi the S1 final shape normalised at the midpoint; F1/F2/odd-row equivalents are psi-weighted means of the facet pressures. Valid for |u_mid| <= 0.1425 m (the S1 final midpoint).
