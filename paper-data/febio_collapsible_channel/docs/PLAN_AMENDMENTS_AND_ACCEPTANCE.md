## Editor's review of amendment A1 (added for this package; the original text follows unchanged)
**Question.** After CC-S1 the strict 160x4 gate (within 3 %) failed by 0.054 percentage points (-3.054 %), the 320x8 gate (within 1 %) passed (-0.757 %), and the tutorial 80x8 mesh failed (-11.63 %). The pre-registered decision tree covered "both fail" (STOP) and the pass branches but not "160x4 fails marginally, 320x8 passes". Amendment A1 switched the coupled problem to the 320x8 wall with a conformal 40/320/80 x 16 = 7,040-cell fluid mesh (tutorial: 3,200 cells).

**Judgement: acceptable as a documented deviation, with four qualifications stated here openly.**
1. *It did not relax a gate.* A1 moved to the only wall that met its pre-registered gate; accepting 160x4 at -3.054 % "because it is close" would have been the post-hoc relaxation. The 160x8 wall has the same in-plane spacing and is at -2.9996 %: the 0.05 pp difference between 160x4 and 160x8 is a thickness-row effect, so the miss is marginal and the strict reading is a conservative one.
2. *It could not favour the coupled outcome.* It selected a more accurate wall (error 0.76 % instead of 3 %), and the amendment states that it was based on S1 only. The later failure (applied-load parity) is a fluid-side finding obtained with the S1 320x8 shape and does not depend on the wall mesh choice.
3. *The ordering claim is only partly verifiable.* The plan file was overwritten in place and no earlier version was kept; the clock times written in the text (about 03:50, 04:05, 04:25 UTC) are later than the Slurm start times (S1 03:42:36, F1 03:44:27, D1 03:47:54) and so cannot be literal (INC-1). What the files do support: the audit file precedes S1; the plan's last modification (03:47:48) is 6 s before the D1 job started, consistent with A2 being written before D1. Whether A1 text existed before the F1 run (03:44:27) cannot be shown from file times alone.
4. *It has costs.* (i) The fluid mesh no longer is the tutorial's (wall-region columns 4x finer, 7,040 vs 3,200 cells), so solids4foam's level-1 error band (4.2-4.82 % history, 1.4 % trough) is not the same discretisation, which A1 says openly; the coupled classification bands of A1/A2 were therefore approximate, and they became moot because no full coupled run was made. (ii) S1 is recorded as PARTIALLY FAILED by the strict gate; the QUALIFIED AGREEMENT label applies to the 320x8 wall only, not to the tutorial mesh (DIAGNOSTIC DISCREPANCY) and not to 160x4.

**Also reviewed: A2.** A2 declared one diagnostic (20 coupled steps) for the F1 force-gate failure (first-mode load -8.63 %, above the 8 % stop value), with a pre-declared refutation criterion (spread above 3 %) and a pre-declared consequence (no full run). The criterion was applied as written (H_D refuted, no full run). The stop rule was not relaxed.
