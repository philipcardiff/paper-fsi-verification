# FEBio v4.13 radialTorsionalRing (torsion member): fixed-geometry fluid evidence, interface-traction discrepancy and coupled-torsion limitation

**Status: DRAFT evidence package.** This is an **independent test of the draft proposal's own reference** (manuscript PR #25 and solids4foam PR #637, written by the same author, not on solids4foam `development`, no second implementation validated it). It is **not verification of the merged suite**. Stock, unmodified FEBio v4.13 (binary sha256 `f5ae1ed6f347f875c392f93d847f2369f437345a9b785296d46b0bd6fbb72f02`, source tag v4.13 clean), 27 Slurm jobs, 0.1350 allocated CPU-h. Only the torsion member was addressed. No stock FEBio source change is proposed and no manuscript change is requested.

## Result in one paragraph
- **Static solid: VERIFIED AGREEMENT (static only).** The FEBio Mooney-Rivlin/NIKE3D law equals the proposal's neo-Hookean law (Cauchy stress identity 1.2e-12), the rotation expression is exact (7e-13 m), and the static finite-strain torsion torque converges to the proposal's reference at observed order 1.95 and 1.99 (3.4e-3, 8.8e-4, 2.2e-4 of the peak at M1-M3). The dynamic solid was not tested separately.
- **Fixed-geometry fluid (RT-B, M1 and M2, one dt = 0.01 s): the pre-registered gates FAILED as run** (velocity error 1.747 % / 1.706 %, ratio 1.02; applied shear torque 12.87 % / 7.47 %, order 0.78). The velocity failure is a time-label offset of the stock v4.13 *fluid module*, which evaluates load-curve boundary values at t - dt/2 at rho_inf = 1 (PROVEN from source and data, confirmed by a diagnostic run). **After alignment for that offset (post hoc, labelled): QUALIFIED AGREEMENT** for the swirl velocity (0.186 % / 0.044 %, order 2.07), the angular momentum H_f (0.168 % / 0.046 %) and the reaction torque (0.26 % / 0.10 %); one dt only, no time-step or K_f study.
- **Shear torque as applied by FEBio's interface traction: DIAGNOSTIC DISCREPANCY with a confirmed first-order mechanism.** 11.42 % (M1) and 5.92 % (M2), order 0.95, after alignment (identical in the shifted-input run); the analytical estimate made before any run (element-mean viscous stress at the element centre) was 11.7 % and 6.0 %.
- **Coupled torsion: NOT ESTABLISHED.** The coupled Newton iteration stalls at the tiny M0 smoke case with the proposal's Mooney-Rivlin law at rho_inf = 1 (hypothesis: FEBio's energy-conserving stress correction on round-off-level energy: SUPPORTED by one diagnostic that removed the stall at M0 but missed its iteration criterion), and the M1 run at rho_inf = 0.9 **diverged at step 2** (32 negative Jacobians). The cause is UNRESOLVED; RT-C M2 was not run.

## Reproducibility
`./reproduce.sh` (Python 3 with numpy, scipy, matplotlib; xz) works in a scratch copy and runs **no simulation**: it verifies the vendored reference hashes, regenerates all FEBio inputs (every gated input bit-identical; four smoke inputs identical modulo NodeSet line order; two superseded first designs shipped as run), re-runs the campaign analysis and an independent re-derivation (own parsers, own algebra, own finite-difference fluid reference) on the stored raw outputs, recomputes the Newton statistics from the solver logs, regenerates tables and figures, regenerates the spectral reference from the omega table, and checks `SHA256SUMS`. Results of the check run made for this package: `provenance/REPRODUCTION_RECORD.md`. The simulations were run with FEBio v4.13 under Slurm; the commands are in the same record.
