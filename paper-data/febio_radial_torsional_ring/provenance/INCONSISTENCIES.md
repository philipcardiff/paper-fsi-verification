# Inconsistencies found while preparing this package, and how each was resolved

The source documents are the campaign's working reports (archived unchanged, apart from removal of a fork account name, in `../docs/archive/`). Every item below was found by checking the working reports against the raw outputs, the sacct accounting, the ledger or the source code. None changes a pass/fail result; items 1-7 would change wording if left uncorrected. The curated documents in `../docs/` and the README use the resolved values.
