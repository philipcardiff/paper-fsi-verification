## Torque and error definitions (fixed now)
Torque of the fluid ON the solid about +z, per radian and per metre of depth = extensive value / (2 pi dz), dz = 0.1. T1 face-evaluated viscous shear torque; T2 = the traction as FEBio applies it (FEFluidFSITraction: Gauss-mean of the attached element, nodal-pressure part separate); T3 = angular-momentum balance (-dH_f/dt + outer flux torque, exact hex8 quadrature); definitions in `RTR_EQUIVALENCE_AUDIT.md` section 3 (implemented in `tools/rtr_analyze.py`; the sign convention is checked against the exact reference in RT-B, a sign or lever error found there is a defect of the analysis, to be fixed and documented, not a FEBio result). **The GATED torque is T2** (the load FEBio actually applies to the solid). Error metric: E_max(q) = max_t |q(t) - q_ref(t)| / max_t |q_ref(t)| over the logged times t_n = n dt (n = 1..200) and E_L2(q) = ||q - q_ref||_L2(t) / ||q_ref||_L2(t) (trapezoid in t) (the proposal's own metrics). Observed order p = log2(E(M1)/E(M2)), quoted only if both errors exceed 3 x the stated floor of the reference (1e-7) and the reference noise (none: deterministic).

## PRE-REGISTRATION OF THE COUPLED-STALL DIAGNOSTIC AND OF THE RT-C CLASSIFICATION RULE (written after the source analysis, before the diagnostic run; the coordinator authorised one diagnostic and RT-C M1 then M2 if it resolves the stall)
**Source analysis (no runs; `RTR_PILOT_RESULTS.md` section 11):** `FEElasticSolidDomain::UpdateElementStresses` (and the three-field domain, l.567) applies an energy-conserving stress correction `s += D ((Wt - Wp)/(dt J) - s:D)/D:D` ONLY when alpha_f == 0.5, i.e. rho_inf = 1, and only when D:D > machine epsilon. With the proposal's law W = U(J) + dev W, U = K/4 (J^2 - 2 ln J - 1), the increment Wt - Wp is cancellation noise (~K/4 x 1e-16) when the strain is ~1e-10; the correction term then is noise/D:D and the tangent contains no such term. The stall started at step 5 (t = 0.05, rotation ~1e-10 rad) where D:D reaches machine epsilon, was independent of the three-field switch (both domains contain the correction), E_mesh, viscosity and outer mesh clamp, and absent for the fluid mixture alone (no solid correction); SVK evaluates W from E without cancellation.
**Hypothesis H-N:** the Newton stall is caused by this correction acting on noise-level strain energy. **Diagnostic (the single run):** SMK_fsi_M0 identical input except rhoi = 0.9 (alpha_f = 0.526, correction inactive; still second order). **Acceptance:** normal termination, 20/20 steps, mean Newton iterations <= 6 per step, no max-reformation error. Pass = H-N supported and the coupled runs use rhoi = 0.9 (amendment A3, applied identically to M1 and M2). Fail = STOP RT-C, coupled torsion NOT ESTABLISHED, no further diagnostics.
**RT-C classification rule (declared before running):** the reduced model with the first-order element-mean traction predicts coupled E_max of alpha_B 8.0 / 4.0 %, H_f 8.2 / 4.1 %, T_B (applied) 6.7 / 3.5 % at M1 / M2 (AE, `tools/rtr_predict_coupled.py`), so the gates alpha_B, H_f <= 5 / 2 % may fail for this known reason.
