## 3. The first-order mechanism (T2)
`FEFluidFSITraction::GetFluidStress` (lines 136-154) averages the viscous stress over **all Gauss points of the attached element** and `LoadVector` (lines 181-189) applies f = gt p - sv gt with that mean: a centroid value at distance h/2 from the wall. The swirl shear stress sigma_rt = mu (L_r/r - 2L/r^2) varies strongly across the first cell (decay length about 0.45 m for the proposal's omega = 3 rad/s). Prediction made before any run (`archive/RTR_PILOT_PLAN.md`; an analytical estimate from the exact solution, shear stress at r = 1 + h/2): E_max(T2) = 11.7 % (M1), 6.0 % (M2), 3.1 % (M3). Observation after alignment: 11.42 % and 5.92 % (2.4 % and 1.3 % below the prediction; the pre-registered confirmation band was +-25 % and a ratio 2.0 +- 0.3: observed ratio 1.93). **DIAGNOSTIC DISCREPANCY with a confirmed first-order mechanism (SUPPORTED: the prediction was made in advance and matched, but no run isolates the sampling location).** The error is not an artefact of the time offset: it is the same 11.4 % in the shifted-input run 14211.

Interpretation for users of stock FEBio: the interface shear traction applied to a structure converges at first order in the radial cell size, 4-12 % of the peak torque at the proposal's M1-M2 meshes (predicted 3.1 % at M3, not run); a face-evaluated T1 is also first order because the face gradient of a piecewise-linear field is a one-cell average. The consistent reaction torque T3 is second-order-like. Whether the first-order traction affects a *coupled* rotation is exactly what RT-C was meant to test (`COUPLED_STALL.md`); the analytical expectation is in `../results/predicted_coupled_element_mean_AE.json` (alpha_B 8.0 / 4.0 %, H_f 8.2 / 4.1 %, T_B applied 6.7 / 3.5 %, sigma_rt 6.7 / 3.5 %) and is an untested estimate.
