# Draft reply to Philip on PR #26 (point by point; to be posted only after the evidence package is pushed)

Thanks, Philip. I ran the K test and completed the missing studies; data are in the updated `paper-data/febio_ring_added_mass/` (new commit on the same draft PR; no manuscript changes). Short answers first, details below.

**2. K = 1e9 Pa, strong M1 (only K changed; `diff` of the two inputs shows only `<k>` and a title comment):** the plateau did **not** drop tenfold, it did not move: wet/dry ratio error +0.035455 % (K = 1e8) -> +0.035595 % (K = 1e9); omega_wet 0.788795780 -> 0.788796881 rad/s (relative change +1.4e-6, equal to the fit-window spread). n=2 pressure, leakage, amplitude loss unchanged. So I can **not** attribute the plateau to compressibility. Linear acoustics in the actual annulus (Helmholtz, rigid wall at 1.5 m, n = 2, c = sqrt(K/rho_f) = 267 m/s) gives a ratio shift of only about -1e-6 relative (-0.0001 %) at K = 1e8: about 280x smaller than the observed +0.0355 % and, in my calculation, of opposite sign (effective added mass increases slightly below the first acoustic resonance). The measured omega shifts agree with that size (strong K 1e8 -> 1e9: +1.4e-6 measured vs +1.1e-6 predicted; moderate M1 K 1e8 -> 1e7, Phase C: -4.0e-6 vs -3.5e-6). I did not run strong M2 at K = 1e9 because the K effect is immaterial. Please check the sign argument; I would not state it in the manuscript without your review.

**2 (floor, continued).** I completed the three-level study at K = 1e8: weak M3 (+0.0042 %) and strong M3 (+0.0410 %). Ratio errors by mesh M1/M2/M3: weak +0.0037/+0.0041/+0.0042 %, moderate +0.0061/+0.0072/+0.0075 %, strong +0.0355/+0.0399/+0.0410 %. All within the 0.1 % band; not decreasing but converging to a mesh-independent floor (observed order about 1.9; extrapolated floors +0.0043 / +0.0076 / +0.041 %). The 25/50/100 steps-per-period study at M2 shows the ratio error is also independent of dt (strong +0.0391/+0.0397/+0.0399 %), while omega converges at order 1.987. Loosening all stopping tolerances 100x (strong M2) changes omega by less than 1e-12 relative (4.55 -> 4.00 Newton iterations per step). So **K, mesh, dt and stopping tolerances are all excluded as the cause**; the floors correspond, in all three regimes and all meshes, to the same shift of omega_wet^2 of about 5e-4 rad^2/s^2, independent of rho_f, which is why it is ten times larger in the strong case. I do not know what produces that shift (not excluded: slip/no-slip model form and weakly enforced w.n = 0, start-up content, amplitude-dependent effects). I can propose two cheap discriminating runs (halved initial amplitude; E_mesh 1e-5) if you want them.

**3. 0.3 % criterion:** reported, not used as pass/fail: M3 absolute errors +0.137 / +0.140 / +0.174 %; omega converges at order 1.98 (hex8).

**4. Raw data:** I used the raw PR #13 CSVs (solids4foam *standard solid*, signed) next to the README values (high-order, unsigned) and label the provenance in every table. Notable: at M2/100 steps the standard-solid IQN-ILS ratio errors are +0.004 / +0.018 / +0.033 % (weak/moderate/strong), the quasi-monolithic ones -0.0002 / -0.0016 / -0.0035 %, FEBio +0.004 / +0.007 / +0.040 %. IQN-ILS errors fall with steps per period; FEBio's and the quasi-monolithic ones do not. I could not compare a solids4foam weak mesh study (not in the PR #13 mesh CSV), and Robin-Neumann only has omega errors in the README.

**1, 5. Scope/labelling:** the FEBio entry stays labelled as the free-slip inviscid-limit problem, a different discrete problem from the solids4foam runs, and the PRs stay separate. A read-only audit suggests a matched free-slip solids4foam variant is plausible (`slip` on the outer wall, `movingWallSlipVelocity` on the interface in OpenFOAM 10) but needs solver-side work and checks of flux/traction consistency; I did not attempt it.
