# Manuscript integration proposal (proposal only; the manuscript is not edited)
1. **Where**: add FEBio as an *independent third-party solver* entry for ringAddedMass: one table (three regimes x FEBio mesh levels, ratio error and omega error, columns beside the solids4foam values) and one sentence on the evidence directory `paper-data/febio_ring_added_mass/`. No change to the Category A status claim.
2. **Wording to use**: "An independent FEBio v4.13 computation of the free-slip (inviscid-limit) problem reproduces the analytical wet/dry frequency ratio to within 0.04 % in the weak, moderate and strong regimes (moderate: +0.006/+0.007/+0.008 % on three meshes), with absolute frequency converging at observed order 1.98 (+0.14 % at the finest level). FEBio solves the free-slip inviscid limit, not the nu_f = 1e-7 no-slip problem solved by solids4foam, so the comparison tests the analytical limit and the coupling, not identical discrete problems."
3. **Lessons worth a sentence**: (i) regulariser stiffness of a massless mesh solid biased the ratio by +0.17 % at E_mesh = 1 Pa and nothing at 1e-3 Pa; (ii) strict no-slip with a nodal constraint did not reproduce the added mass (-6 % / -2.7 %); (iii) weakly-enforced interface w.n = 0 leaves 0.3-1.2 % rms leakage; (iv) the nodal-traction n=2 force has a first-order sampling offset (-2.1 -> -0.5 %).
4. **Do not claim**: FEBio "verified" (the mesh-independent floor of the ratio error, +0.0043 / +0.0076 / +0.041 % for weak/moderate/strong, is unexplained although K, time step, mesh and stopping tolerances are excluded by measurement; the model is the free-slip inviscid limit, not the finite-viscosity no-slip problem); solver speed comparisons. (Updated after the final campaign: time order 1.987 is now measured, the three-level mesh study is complete, the iterative error is bracketed for strong M2; see RING_FINAL_COMPARISON.md.)
